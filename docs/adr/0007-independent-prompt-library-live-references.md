# ADR 0007：独立词库与实时词条引用

Status: Accepted.

## 背景

词库需要被多个工作流共享，并且词条编辑应立即影响所有引用节点。如果把完整词库或词条正文复制到每个工作流，会产生多份真源；如果只保存显示名称，又会在重名、改名或删除后错误匹配。预览图和大体积备份也不适合进入工作流 JSON。

## 决策

Prompt Library 使用 ComfyUI 用户目录中的独立 SQLite 存储。Prompt Entry 使用稳定 ID，预览资源按内容哈希保存；批量写入与导入应用在 SQLite 事务中完成。

PromptSelector 只在工作流内保存有序 Prompt Entry ID、权重和节点级分隔符。执行前端按 ID 解析当前正文并注入内部 payload，使词条变更参与缓存键。词条缺失时保留 Missing Reference 并阻止执行，不按标题或正文猜测替代项。

词库备份使用带版本 manifest 与哈希资源的 ZIP；导入先预检，再显式应用冲突策略。备份大小与解压资源设置公开上限，传输和解压使用磁盘暂存与流式读写，避免不受控内存占用和压缩包资源耗尽。侧边栏预设保持为独立 JSON；二者不互相嵌套，以免布局恢复意外覆盖用户词库。

## 结果

- 词库只有一个持久真源，编辑后所有引用节点都使用最新正文。
- 工作流文件保持紧凑，预览图不会进入工作流序列化。
- 工作流离开原用户目录后，必须先迁移对应词库备份，才能恢复完整引用。
- 删除词条不会静默改变工作流语义；用户必须恢复或移除失效引用。
- 词库备份和 Dashboard Preset 分开迁移，用户可以独立恢复内容与布局。
