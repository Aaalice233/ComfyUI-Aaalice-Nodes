# Architecture Decision Records

ADR 只记录难逆、令人意外且存在真实方案取舍的当前或已发布决策。状态使用：

- `Accepted`：当前有效。
- `Superseded by ADR NNNN`：已发布决策被后继 ADR 替代，保留历史。
- `Rejected`：评估后未采用且结论仍有长期参考价值。
