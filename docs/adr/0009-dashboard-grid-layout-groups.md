# ADR 0009：Dashboard 使用结构化网格与可选布局组

Status: Accepted.

## 背景

强制的“页面—分区—卡片”层级让只有一组参数的页面承担了无意义的分区管理；完全自由的像素画布又会在窄侧栏中引入重叠、横向滚动、尺寸测量和响应式漂移。

## 决策

Dashboard Page 直接持有参数卡片和分隔项，并使用持久化的双列细粒度逻辑网格。每个卡片保存横向与纵向逻辑跨度，碰撞按完整矩形占位判断，因此矮卡片可以填入高卡片旁边的剩余纵向空间；跨度来自稳定的控件展示类别，不依赖 DOM 测量。Layout Group 是可选、单层、全宽的组合，组内复用同一网格；卡片只保存一个 Group Id，组不重复保存成员列表。单列界面只是渲染投影，不回写布局。布局不保存像素坐标、DOM 尺寸、嵌套组或重叠关系。

## 结果

- 没有分组需求的页面不显示额外层级。
- 来自不同 Control Host 的参数卡片可以组成一个可整体移动的布局组。
- 不同高度的卡片拥有真实二维占位，可独立填充同列中的纵向空位。
- 网格碰撞、整理、响应式投影和分组命令可作为纯逻辑测试。
- 牺牲任意坐标、重叠和嵌套能力，换取窄侧栏中的稳定阅读顺序与可维护性。
