# ResolutionPreset 设计规范

## 职责

`ResolutionPreset` 只选择并输出精确 `width` 与 `height`。它提供内置预设、当前用户的个人预设、手动数字输入和二维画幅拖拽，不按百万像素反推尺寸，不推荐模型，也不创建、裁剪、缩放图像或 Latent。

官方 `ResolutionSelector` 适合按宽高比与目标百万像素计算尺寸；本节点适合直接操作确定像素尺寸。只读的宽高比和 MP 摘要用于辨认当前画幅，不参与计算或执行协议。

## 信息层级

```text
┌ 预设 / 自定义━━━━  8 px  ≤ 2048  ⇄  保存            ┐
│  ┌───────────────────────────────────────────────┐  │
│  │ · · · · · · · · · · · · · │                    │
│  │ · · · ●━━━━━━○ · · · · · · │                    │
│  │ · · · ┃      ● · · · · · · │                    │
│  │ · · · ┗━━━━━━┛ · · · · · · │                    │
│  └ [W 1024] [H 1024]        1:1 · 1 MP ┘            │
└──────────────────────────────────────────────────────┘
```

- 顶栏集中预设、像素对齐、最大范围、交换宽高和保存当前；预设入口吸收剩余宽度，使整行控件横向占满，两个工具按钮使用一致且清晰的图标表面。
- 画幅坐标板是视觉核心；选择矩形固定在左下原点，向右、向上扩展。右边、上边和右上角分别控制宽、高及二者。
- 状态胶囊位于顶栏，只切换像素对齐和画布最大范围。画板底部使用扁平信息层：`W`、`H` 标识与数值输入构成低对比的成对控件，比例和 MP 摘要留在另一侧；只有悬停和聚焦时才提升表面强度。
- Canvas/native 层保留真实输出槽、标题拖拽和原生缩放；DOM overlay 只承载交互。

## 画幅交互

- 坐标板空白区不响应点击。三个控制柄是可聚焦 `button`，使用 Pointer Capture；拖拽过程只预览，释放后提交一次图历史。
- `Escape`、`pointercancel` 和窗口失焦恢复拖拽前快照。拖拽期间不切换最大范围，结束后才按需要升到最小可容纳档位。
- 宽度柄使用左右键，高度柄使用上下键，角柄同时支持两组方向键；`Shift` 使用四倍步长。连续按键合并为一次历史手势。
- 拖拽使用当前 alignment 四舍五入并限制到合法范围。网格只帮助判断方向和比例，其密度不等于 8 px 对齐点阵。
- 最大范围的三个档位始终可选。切换到小于当前宽高的档位时，节点按原宽高比自动缩小到新范围并执行当前像素对齐；选项在提交前展示精确结果，整次适配只生成一条图历史。

## 预设与输入

- 内置预设按正方形、竖版和横版分组，不附带模型名称，并包含 `1080×1920` / `1920×1080` 横竖变体。当前项同时显示选中表面与勾选；若尺寸无法满足当前 alignment，则采用该内置预设的 8 px 对齐，禁止把预设尺寸静默取整为其它数值。
- 个人预设保存稳定 UUID、名称、宽、高和 alignment；用户可新建、重命名和删除。服务失败不得阻断节点恢复、手动编辑或执行。
- 手动输入仅在 `Enter` 或失焦时提交。未满足当前对齐时保留旧值，显示所需倍数和最近合法值，并提供显式采用动作。
- 尺寸变化后重新精确匹配预设；不能精确匹配时统一显示“自定义”。`presetId` 只是显示提示，宽高始终是执行真源。

## 视觉与适配

- 默认约 `320×270`，稳定最小内容宽高约 `280×240`。中央画幅板始终保持正方形与双轴同尺度，使用当前可用空间并限制为最高 `320px`；节点继续拉高时，新增空间留在画幅板下方，不拉伸点阵、选区或底部尺寸摘要。缩短时保持画幅板和输出侧小部件可用，不从当前 DOM 几何反推最小尺寸。
- 画幅选区与普通激活态使用 Node Accent 的柔色表面；文字、网格、错误和背景来自共享主题 token。
- 坐标板使用无渐变的深色实面与稠密低对比点阵；点阵密度与 Pixel Alignment 解耦，最大范围只作为画幅可缩放边界。
- 选区使用轻薄完整轮廓和极低强度填充。高度柄为暖色圆点，宽度柄跟随 Node Accent，右上角双向柄为高对比圆点；三者都保留宽松透明命中区。
- 普通区域不用连续分割线或第二层节点外壳。所有用户文字至少 10 px，字段和主标签至少 11 px。
- 画幅变化使用约 160 ms 的短过渡；`prefers-reduced-motion` 下关闭。Classic 与 Nodes 2.0 必须保留底部和四角原生缩放命中。
