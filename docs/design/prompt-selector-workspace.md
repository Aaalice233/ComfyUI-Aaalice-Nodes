# PromptSelector、词库与 DIY 侧边栏

本文定义 PromptSelector 节点、左侧 Aaalice Workspace 和词库管理界面的职责、组件结构与交互。状态真源和服务端数据流见架构与 ADR 0007、0008。

## 组件边界

- `js/lib/ui.js` 提供无业务状态的按钮、字段、Dialog、Popover、空状态和可访问性基础组件。
- Workspace 复合组件提供页面标签、工具栏、分区、参数卡片和列表行；只接收数据与回调，不读取图或词库。
- Store 负责状态规范化、序列化和服务端事件；Control Provider 负责发现、解析和写回不同参数来源。
- PromptSelector、Dashboard 和 Library View 只编排组件，不复制基础控件与主题规则。词库派生索引、定高虚拟列表和图片预览分别由共享模块提供，两处条目界面不得各自实现一套。

## PromptSelector

- 节点主体保持条目式，只放搜索、分类/合集筛选、跨分类多选列表和已选数量。
- 每条词条以缩略图代替独立复选框，选中态使用主题色覆层和勾选标记；缩略图内部仍保留可聚焦的原生 checkbox，文字标签与其关联。
- 带预览图的词条在鼠标稳定停留 300–400ms 或键盘聚焦时显示共用大图浮层；快速扫过不触发，键盘聚焦立即响应。浮层按图片原始比例收口，标题叠放在底部半透明信息层，不为横竖图强制保留黑边。无图词条显示可选择的占位图，但不打开浮层。
- 词条右侧文字区域在悬停或键盘聚焦时显示独立信息卡，完整呈现标题、提示词正文、分类、合集、标签和备注；正文不截断，长内容只在信息卡内部滚动。图片预览与信息卡都按需复用单例 Tooltip，不随词条总量增加常驻浮层，也不得拦截鼠标点击、滚轮、拖动或画布命中。
- 权重与顺序集中在“管理已选提示词”Dialog 中处理；分隔符放在节点右键设置，不占主列表空间。
- 节点只保存词条 ID、权重、选择顺序和分隔符。缺失词条以错误状态保留并阻止执行。
- 列表滚动属于节点内部内容区。Classic 与 Nodes 2.0 都必须保持有界高度，虚拟列表的总高度占位不得参与节点自身最小高度测量，也不得遮挡原生缩放角。

## 左侧工作区

Aaalice Workspace 注册在 ComfyUI 左侧，包含“参数控制”和“词库管理”两个工作区。所有 Dashboard Page 均由用户手工创建；页面包含有序分区，分区包含参数卡片、分隔项和空白项。

普通模式只允许切换页面、滚动、圆点导航和调参。节点右键“📌 添加参数到侧边栏…”始终可用，与编辑模式无关。编辑模式只开放页面/分区/卡片的创建、复制、删除、拖动、跨区移动、宽度、紧凑样式和布局项调整。

添加参数 Dialog 先选择参数，再选择目标页面和分区。没有页面时可在同一流程创建首个页面与分区；重复绑定默认禁用，用户可显式允许镜像卡片。子图只列出子图整体对外公开的兼容参数，不进入内部图。

## 词库与导入导出

词库工作区提供搜索、分类、合集、标签、词条编辑、单张预览图和完整/筛选导出。导入必须先显示新增、已有、冲突、重复和无效数据，再由用户为冲突选择保留本地、使用导入或创建副本。

词库 ZIP 只上传一次并暂存到服务端，确认后使用 token 应用；导入、解压与导出上限为 2 GiB，上传、解压和下载均避免整包驻留内存。Dashboard Preset 单独导入导出，精确绑定失败时保留 Missing Binding 并允许人工重绑。

## 性能与生命周期

- 主词库和 PromptSelector 共用快照级索引、定高虚拟列表与图片预览服务，不分别维护派生数据和监听器。
- DOM 行数只随可视区域与少量 overscan 变化，不随词条总数线性增长；筛选只替换索引结果，不为每条词条注册常驻观察器。
- 图片使用惰性加载；大图预览复用单例浮层，锚点离开、条目重用或视图销毁时必须清理当前预览。
- 词库事件按受影响范围刷新。图变化和连续输入合并更新，不使用轮询，也不在每个按键后重建整个工作区。
- Dialog、Popover、文件输入、全局事件和 `AbortController` 在所属视图销毁时释放；仍有效的焦点和操作状态不得因局部刷新丢失。

## 交互与可访问性

- 内容区自然竖向滚动，圆点 rail 跳转当前页面分区；页面切换位于顶部。
- 拖动只在编辑模式启用；普通调参不会误改布局。
- 颜色使用 ComfyUI token；错误、缺失、禁用和选中状态同时提供文字或形态信息。
- Dialog、文件输入、列表复选框和纯图标按钮必须具备可访问名称；销毁工作区时清理监听器和挂载内容。

## 视觉层级

- 工作区使用紧凑品牌头、双工作区分段导航、页面导航、分区标题和参数卡片五级层次；同一层不重复套边框。
- 参数卡片默认弱化管理按钮，悬停、键盘聚焦或进入布局编辑模式时再完整显示；参数值始终比管理操作更醒目。
- 参数来源使用小型形态标记区分普通参数、Aaalice 参数和子图公开参数，但不能只靠颜色表达 Missing Binding。
- PromptSelector 以条目选中表面、分类短标签和底部数量摘要提高扫读效率，不在 DOM overlay 上复制节点外壳。
- 分区圆点导航应跟随当前可见分区，并在销毁或重绘时释放观察器。
