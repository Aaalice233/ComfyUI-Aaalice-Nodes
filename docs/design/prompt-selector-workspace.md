# PromptSelector、词库与 DIY 侧边栏

本文定义 PromptSelector 节点、左侧 Aaalice Workspace 和词库管理界面的职责、组件结构与交互。状态真源和服务端数据流见架构与 ADR 0007、0008。

## 组件边界

- `js/lib/ui.js` 提供无业务状态的按钮、字段、Dialog、Popover、空状态和可访问性基础组件。
- Workspace 复合组件提供页面 rail、工具栏、十二列细分网格、布局组、参数卡片和列表行；只接收数据与回调，不读取图或词库。页面 rail 按 Page Id 复用 DOM，并从实际按钮几何定位指示器。
- Store 负责状态规范化和序列化；Control Provider 只负责发现、解析和写回不同参数来源，`workspace_controls.js` 独立负责把解析结果渲染成控件及处理连续手势。
- PromptSelector、Dashboard 和 Library View 只编排组件，不复制基础控件与主题规则。词库派生索引、定高虚拟列表和图片预览分别由共享模块提供，两处条目界面不得各自实现一套。

## PromptSelector

- 节点主体保持条目式，只放搜索、分类/收藏夹筛选、跨分类多选列表和已选数量。
- 每条词条由职责分离的缩略图和文字选择区组成：缩略图只负责悬浮预览与双击快速编辑，不激活或取消词条；文字区是可聚焦的选择按钮，负责即时切换选择状态。选中态由整行主题色表面和 `aria-pressed` 共同表达，不在缩略图内伪装复选框。
- 带预览图的词条在鼠标稳定停留 300–400ms 或键盘聚焦时显示共用大图浮层；快速扫过不触发，键盘聚焦立即响应。浮层按图片原始比例收口，标题叠放在底部半透明信息层，不为横竖图强制保留黑边。无图词条显示可选择的占位图，但不打开浮层。
- PromptSelector 的文字区域点击或键盘激活后须立即切换选择；缩略图单击只聚焦，不改变选择，快速双击则打开对应词条编辑器。缩略图悬浮提示明确写出“双击缩略图可快速编辑词条”，避免把隐藏手势留给用户猜测。Library View 继续使用缩略图选择语义，两处不得因共享预览组件而混淆业务职责。右侧独立操作按钮不触发选择。文字区域在悬停或键盘聚焦时显示共享信息卡，完整呈现标题、提示词正文、分类、收藏夹、标签和备注；正文不截断，长内容只在信息卡内部滚动。图片预览与信息卡都按需复用单例 Tooltip，不随词条总量增加常驻浮层，也不得拦截鼠标点击、滚轮、拖动或画布命中。
- 已选词条悬停或键盘聚焦时显示紧凑权重控件；滚轮或方向键以 `0.1` 调整，按住 `Shift` 时以 `0.01` 微调，点击控件快速重置为 `1`。权重范围保持 `0–20`，分隔符放在节点右键设置，不占主列表空间。
- 工具栏默认按最近执行使用排序，时钟图标按钮可恢复词库手工顺序；分类、收藏夹和搜索继续作用于当前排序结果。一次工作流排队会把实际进入 PromptSelector 执行 payload 的词条记为同一批最近使用，未使用词条保持原有稳定顺序。最近使用记录属于当前 ComfyUI 用户的词库元数据，不进入工作流或词库备份。
- 节点只保存词条 ID、权重、选择顺序和分隔符。缺失词条以错误状态保留并阻止执行。
- 新建节点默认尺寸与可缩放下限均为 `440 × 560`，保证筛选栏、词条列表和底部摘要在常用画布比例下拥有稳定空间；加载已有工作流时，小于下限的保存尺寸会按新下限显示。
- 列表滚动属于节点内部内容区。Classic 与 Nodes 2.0 都必须保持有界高度，虚拟列表的总高度占位不得参与节点自身最小高度测量，也不得遮挡原生缩放角。Nodes 2.0 下 DOM widget 必须留在宿主分配的 widget 行内，不得绝对定位到整个节点并覆盖原生标题、输入输出槽或底部节点包标记。
- 词条列表使用 ComfyUI 当前前端的焦点式滚轮捕获协议：滚动根同时声明 `tabindex="0"` 与 `data-capture-wheel="true"`；普通滚轮进入未聚焦列表时，在事件冒泡到 Nodes 2.0 宿主前只执行 `focus({ preventScroll: true })`。焦点位于列表或其后代时由浏览器滚动列表；焦点在外部时继续服从当前画布导航模式；Standard 模式的 `Ctrl` / `Meta` + 滚轮不得被列表抢焦点或拦截。业务层禁止 `preventDefault()`、`stopPropagation()`、捕获阶段监听和伪造滚轮转发。
- 该协议以当前安装版 ComfyUI Frontend 的 `useCanvasInteractions` 为实现真源；官方 `addDOMWidget` 文档未承诺 `data-capture-wheel`。升级前端后若滚轮行为变化，先对照同版本官方内置 DOM widget 和前端源码，不增加私有时序补丁。

## 左侧工作区

Aaalice Workspace 注册在 ComfyUI 左侧，包含“参数控制”和“词库管理”两个工作区。所有 Dashboard Page 均由用户手工创建；页面直接包含参数卡片、可命名分隔线和可选 Layout Group，不存在强制分区或空白项。

顶栏图钉控制点击侧边栏外部时是否自动收起：默认固定，关闭图钉后启用自动收起。该选择是浏览器级界面偏好，切换后立即持久化并在刷新后恢复，不写入工作流或触发工作流未保存提示。

使用 ComfyUI 原生 `INT`、`FLOAT`、`BOOLEAN`、`STRING`、`COMBO` 控件的简单节点自动进入兼容范围，并通过节点右键选择参数加入当前页面。原生 `ImageCompare` 由内置显式 Adapter 投影为只读媒体卡片，复用其最近一次执行结果并以执行回调驱动刷新；临时预览 URL 不写入工作流或侧边栏预设，预设只保存布局和稳定 Binding。带未知自定义 widget 或 DOM 面板的节点不做部分投影，必须通过公开 Adapter API 显式声明稳定身份、读取、写回和渲染策略；因此新增第三方适配不会扩大或修改原生 fallback 的判断范围。

普通模式只允许切换页面、滚动、圆点导航和调参。节点右键“📌 添加参数到侧边栏…”始终可用，与编辑模式无关。编辑模式开放页面、卡片、分隔线和布局组的创建、复制、删除、网格拖动、跨页移动、宽度与紧凑样式调整；参数控件在编辑期间只读。

普通模式和布局模式都在页名之后提供紧凑的侧边栏预设选择器。每个预设同时保存全部 Dashboard 页面、分隔线、布局组、卡片网格几何、稳定 Binding 和兼容参数值；Seed 参数的保存值同时包含数值和执行后行为，因此锁定、随机、递增与递减状态会随预设切换。重复投影同一 Binding 时只保存和应用一次。入口保持单行：当前状态完全匹配基准预设时显示其名称，布局或参数发生有效偏离后仍显示基准预设名称，并使用斜体和末尾 `*` 表示尚未保存；没有基准预设时显示“未保存”。提示中说明布局和参数差异数量。弹层以选择为主操作：顶栏直接提供紧凑的“新增”按钮，不再折叠进操作菜单；悬浮或键盘聚焦条目时直接显示重命名、复制和删除三个快捷按钮；有基准的修改状态只显示“保存修改”和“放弃修改”，无基准时只显示“保存为预设”。

切换侧边栏预设前检查当前 Working Copy：有基准时提供更新并切换、放弃并切换和取消；无基准时提供另存并切换、放弃并切换和取消。应用前按稳定 Binding、值类型和第三方 codec 完整预检，异常项进入复核列表；用户确认后保留失效卡片并应用其余兼容内容。布局替换和参数写入必须处于同一个图历史边界，任一写入失败时同时回滚布局与所有已写参数。预设集合和基准身份保存在 `app.graph.extra.aaaliceSidebarPresets`，参数值仍由原节点拥有；保存到预设与保存工作流是两种明确操作。

预设捕获和应用必须尊重控件的瞬时可用性：暂不可用或未赋值的现有 Binding 在保存修改时保留原保存值，不把暂时故障误判为用户修改；真正缺失、不兼容或报错的 Binding 使当前状态显示“已修改 + 需要处理”。第三方 codec 必须同步执行，写入失败时连同“已写入后才抛错”的当前项一起逆序回滚。内部快速预设与外部 JSON 备份复用同一快照、校验和预检协议；导入时要求确认预设名称，在同一事务中创建并应用新的基准预设。0.2.0 不兼容旧版纯参数预设，检测到旧集合时直接清空并提示保存工作流。

添加参数 Dialog 同时呈现目标页面与可选参数；参数区提供全选/全不选，且只作用于当前允许添加的参数。没有页面时可在同一流程创建首个页面；重复绑定默认禁用，用户可显式允许镜像卡片。页面下拉复用共享 `selectControl()`，避免宿主样式覆盖原生箭头。子图只列出子图整体对外公开的兼容参数，不进入内部图。

Dashboard 持久化十二列细分逻辑网格而非像素位置；默认半宽卡片占六列，宽高都保存为整数网格跨度并可在布局模式直接调整。窄侧栏只投影为单列，不回写规范宽度。卡片不可重叠；移动或缩放发生碰撞时，只让本次操作的卡片或布局组顺延到最近可用行，不改动其它布局项及既有空隙，“整理布局”只由用户显式触发。框选后的整体拖动以同一网格作用域内的选区包围盒吸附，原子提交全部成员的新坐标并保持内部相对布局，不允许选中项互相触发碰撞整理。Layout Group 横跨十二列，组内复用同一细粒度网格；打组时把成员的页面坐标转换为组内相对坐标，解除整组时再还原为页面坐标，二者都不得整理其它布局项。组的外部占位由组内内容确定，组不嵌套、不折叠。

Layout Group 的视觉层是一张组合卡片，而不是外框内再堆多张完整卡片。成员控件取消独立边框和投影，使用统一中性背景融入组合外壳，同时继续作为可单独选择、移动、缩放和解绑的布局项。该组合语义由 Dashboard 视图层统一添加，Control Renderer 不感知成员是否位于组内。

## 词库与导入导出

词库工作区提供搜索、分类、收藏夹、标签、词条编辑、单张预览图和完整/筛选导出。已选操作栏固定承载移动、导出、危险确认删除与全选/全不选；导出作用于当前已选词条，批量删除必须保持事务原子性。默认收藏夹始终存在且不可删除；PromptSelector 的收藏按钮从词库快照派生状态，收藏时选择目标收藏夹，取消收藏时移除该词条的全部收藏关系。导入必须先显示新增、已有、冲突、重复和无效数据，再由用户为冲突选择保留本地、使用导入或创建副本。

词库 ZIP 只上传一次并暂存到服务端，确认后使用 token 应用；导入、解压与导出上限为 2 GiB，上传、解压和下载均避免整包驻留内存。Dashboard 布局备份单独导入导出，精确绑定失败时保留 Missing Binding 并允许人工重绑。

## 性能与生命周期

- 主词库和 PromptSelector 共用快照级索引、定高虚拟列表与图片预览服务，不分别维护派生数据和监听器。
- DOM 行数只随可视区域与少量 overscan 变化，不随词条总数线性增长；筛选只替换索引结果，不为每条词条注册常驻观察器。
- 图片使用惰性加载；大图预览复用单例浮层，锚点离开、条目重用或视图销毁时必须清理当前预览。
- 词库事件按受影响范围刷新。图变化和连续输入合并更新，不使用轮询，也不在每个按键后重建整个工作区。
- Dialog、Popover、文件输入、全局事件和 `AbortController` 在所属视图销毁时释放；仍有效的焦点和操作状态不得因局部刷新丢失。

## 交互与可访问性

- 内容区自然竖向滚动；右侧页面 rail 采用覆盖式滚动条语义。鼠标进入右侧 rail 热区或键盘焦点进入导航后，所有页面圆点同时各自向左展开为独立胶囊并显示页面名称，而不是合并成一个容器或要求逐个悬停。点击、在 rail 上滚轮滚动以及 `ArrowUp` / `ArrowDown`、`PageUp` / `PageDown`、`Home` / `End` 均可切换页面；滚动到首尾后停止，不循环。滚轮切页期间 rail 保持稳定展开，不通过收拢、重展开或定时闪现反馈；rail、圆点和当前页指示器在切页时保持 DOM identity，指示器按目标圆点的实际 `offsetTop` 平移，不依赖重建前后状态或固定步距。展开时同一指示器扩展为整个高亮胶囊，不能用淡入淡出、弹跳或延迟阻塞切页。当前项保留 `aria-current`，布局组不占用独立导航层。
- 拖动只在编辑模式启用；普通调参不会误改布局。
- 颜色使用 ComfyUI token；错误、缺失、禁用和选中状态同时提供文字或形态信息。
- Dialog、文件输入、列表复选框和纯图标按钮必须具备可访问名称；销毁工作区时清理监听器和挂载内容。

## 视觉层级

- 工作区使用紧凑品牌头、双工作区分段导航、页面导航、可选布局组和参数卡片建立层次；没有组时不显示额外标题。
- “布局”是低频结构模式入口：普通态使用弱化的无边框按钮，不与参数调节争夺视觉焦点；进入编辑模式后才以柔和强调底色显示“完成”，同时呈现页面、网格、布局组和卡片管理操作。
- 参数卡片不常驻设置或布局按钮；右键、`ContextMenu` 或 `Shift+F10` 打开共享上下文菜单。普通模式提供重绑与移除，布局编辑模式再追加移动、宽度和紧凑度操作；文本输入区域保留浏览器原生编辑菜单。参数值始终比管理操作更醒目。
- Seed 与其它无有效范围的数字只占用卡片标题行，数值和锁定按钮保持同一基线；网格使用内容高度而非同行最大卡片高度，不能因为邻近滑条而留下空白下半区。
- 数值参数卡片复用 ParameterPanel 的“范围 + 精确值”心智模型：适合范围调节的有界数值使用紧凑滑条与可点击数值，Seed 和无可靠范围的数字只显示精确值，避免无意义滑条；Seed 同时复用锁定按钮，锁定写入 `fixed`，解锁写入 `randomize`，与节点面保持同一状态真源。点击数值进入精确编辑，控件区域滚轮和方向键按 step 调整，按住 `Shift` 以十倍步长快速调整。一次连续拖动或滚轮手势只形成一个图历史边界。
- 枚举和布尔参数分别复用共享 `selectControl()` 与 `toggleSwitch()`；图像参数与 ParameterPanel 复用同一个 32px 图像控件、上传链路、拖放反馈、即时完整预览和清空交互，侧边栏只映射主题 token，不另造一套表现。文本、其它文件和缺失绑定保留清晰的输入或修复入口，不用相同外形伪装成滑条。
- 参数卡片不使用类型色或标题前置圆点区分来源；控件统一使用当前主题强调色，Missing Binding、不可用和 Seed Lock 等语义状态继续通过边框、背景、图标或文字明确表达。
- PromptSelector 以条目选中表面、分类短标签和底部数量摘要提高扫读效率，不在 DOM overlay 上复制节点外壳。
- 页面 rail 默认收拢以让出内容宽度；展开后每个页面仍是边界清楚的独立胶囊，共享对齐和间距但不合并外壳。页面名称固定靠胶囊左侧排列，圆点留在右侧鼠标热区，避免指针遮挡文字。胶囊以主题表面、轻边框和克制阴影覆盖内容边缘，不推动参数布局。页面管理操作只在编辑模式显示。展开不能依赖颜色作为唯一反馈，动效遵循 reduced-motion 设置。
