# PromptSelector、词库与 DIY 侧边栏

本文定义 PromptSelector 节点、左侧 Aaalice Workspace 和词库管理界面的职责、组件结构与交互。状态真源和服务端数据流见架构与 ADR 0007、0008。

## 组件边界

- `js/lib/ui.js` 提供无业务状态的按钮、字段、Dialog、Popover、空状态和可访问性基础组件。
- Workspace 复合组件提供页面 rail、工具栏、十二列细分网格、布局组、参数卡片和列表行；只接收数据与回调，不读取图或词库。页面 rail 按 Page Id 复用 DOM，并从实际按钮几何定位指示器。
- Store 负责状态规范化和序列化；Control Provider 只负责发现、解析和写回不同参数来源，`workspace_controls.js` 独立负责把解析结果渲染成控件及处理连续手势。
- PromptSelector、Dashboard 和 Library View 只编排组件，不复制基础控件与主题规则。词库派生索引、定高虚拟列表和图片预览分别由共享模块提供，两处条目界面不得各自实现一套。

## PromptSelector

- 节点主体保持条目式，只放搜索、分类/收藏夹筛选、跨分类多选列表和已选数量。
- 搜索框通过 `data-autocomplete-plus` 属性接入 Autocomplete-Plus 的标签与中文补全；候选面板打开期间输入框带有 `data-autocomplete-plus-open`，此时搜索框自身的按键处理（如 Esc 收起）必须整体让位给补全面板。Autocomplete-Plus 未安装时搜索框行为不变。
- 每条词条由职责分离的缩略图和文字选择区组成：缩略图只负责悬浮预览与双击快速编辑，不激活或取消词条；文字区是可聚焦的选择按钮，负责即时切换选择状态。选中态由整行主题色表面和 `aria-pressed` 共同表达，不在缩略图内伪装复选框。
- 带预览图的词条在鼠标稳定停留 300–400ms 或键盘聚焦时显示共用大图浮层；快速扫过不触发，键盘聚焦立即响应。浮层按图片原始比例收口，标题叠放在底部半透明信息层，不为横竖图强制保留黑边。无图词条显示可选择的占位图，但不打开浮层。
- PromptSelector 的文字区域点击或键盘激活后须立即切换选择；缩略图单击只聚焦，不改变选择，快速双击则打开对应词条编辑器。缩略图悬浮提示明确写出“双击缩略图可快速编辑词条”，避免把隐藏手势留给用户猜测。Library View 继续使用缩略图选择语义，两处不得因共享预览组件而混淆业务职责。右侧独立操作按钮不触发选择，其中复制按钮把该词条完整正文写入剪贴板并给出 toast 与按钮确认动画，不截断、不拼接。文字区域在悬停或键盘聚焦时显示共享信息卡，完整呈现标题、提示词正文、分类、收藏夹、标签和备注；正文不截断，长内容只在信息卡内部滚动。图片预览与信息卡都按需复用单例 Tooltip，不随词条总量增加常驻浮层，也不得拦截鼠标点击、滚轮、拖动或画布命中。
- 已选词条悬停或键盘聚焦时显示紧凑权重控件；滚轮或方向键以 `0.1` 调整，按住 `Shift` 时以 `0.01` 微调，点击控件快速重置为 `1`。权重范围保持 `0–20`，分隔符放在节点右键设置，不占主列表空间。
- 工具栏默认按最近执行使用排序，时钟图标按钮可恢复词库手工顺序；分类、收藏夹和搜索继续作用于当前排序结果。一次工作流排队会把实际进入 PromptSelector 执行 payload 的词条记为同一批最近使用，未使用词条保持原有稳定顺序。最近使用记录属于当前 ComfyUI 用户的词库元数据，不进入工作流或词库备份。
- 节点只保存词条 ID、权重、选择顺序和分隔符。缺失词条以错误状态保留并阻止执行。
- 新建节点默认尺寸与可缩放下限均为 `440 × 560`，保证筛选栏、词条列表和底部摘要在常用画布比例下拥有稳定空间；加载已有工作流时，小于下限的保存尺寸会按新下限显示。
- 列表滚动属于节点内部内容区。Classic 与 Nodes 2.0 都必须保持有界高度，虚拟列表的总高度占位不得参与节点自身最小高度测量，也不得遮挡原生缩放角。Nodes 2.0 下 DOM widget 必须留在宿主分配的 widget 行内，不得绝对定位到整个节点并覆盖原生标题、输入输出槽或底部节点包标记。
- 词条列表使用 ComfyUI 当前前端的焦点式滚轮捕获协议：PromptSelector 业务根声明 `data-capture-wheel="true"`，列表声明 `tabindex="0"`。Nodes 2.0 宿主在捕获阶段先处理 `wheel`，所以列表不能等到自身 `wheel` 回调再补焦点；指针从画布进入列表时通过 `pointerenter` 预先执行 `focus({ preventScroll: true })`，从而无需点击即可让第一段普通滚轮滚动列表。若外部文本输入仍在编辑则不抢焦点；焦点已在 PromptSelector 的筛选或操作控件内时，业务根同样满足捕获条件。Standard 模式的 `Ctrl` / `Meta` + 滚轮继续由宿主处理。业务层禁止 `preventDefault()`、`stopPropagation()`、捕获阶段监听和伪造滚轮转发。
- 该协议以当前安装版 ComfyUI Frontend 的 `useCanvasInteractions` 为实现真源；官方 `addDOMWidget` 文档未承诺 `data-capture-wheel`。升级前端后若滚轮行为变化，先对照同版本官方内置 DOM widget 和前端源码，不增加私有时序补丁。

## 左侧工作区

Aaalice Workspace 注册在 ComfyUI 左侧，包含“参数控制”和“词库管理”两个工作区。所有 Dashboard Page 均由用户手工创建；页面直接包含参数卡片、可命名分隔线和可选 Layout Group，不存在强制分区或空白项。

顶栏图钉控制点击侧边栏外部时是否自动收起：默认固定，关闭图钉后启用自动收起。该选择是浏览器级界面偏好，切换后立即持久化并在刷新后恢复，不写入工作流或触发工作流未保存提示。

使用 ComfyUI 原生 `INT`、`FLOAT`、`BOOLEAN`、`STRING`、`COMBO` 控件的简单节点自动进入兼容范围，并通过节点右键选择参数加入当前页面。带 `image_upload` 的图像 Combo 使用缩略图选择器和共享大图预览，并按节点声明的 `input` / `output` / `temp` 目录解析 `/view`，不得把输出图像固定按输入目录读取。原生 `ImageCompare` 由内置显式 Adapter 投影为只读媒体卡片，复用其最近一次执行结果并以执行回调驱动刷新。点击媒体区域打开占满当前窗口的共享 Dialog；查看器同步当前 A/B batch 与分割位置，支持最高 8 倍的指针中心缩放、放大后受边界约束的拖动、随指针位置实时变化的无手柄分割线、键盘微调和一键适应屏幕。底栏按画面语义稳定分为三列：图像 A 导航靠左、缩放控制严格居中、图像 B 导航靠右；窄屏时 A/B 保持两端，缩放控制单独进入下一行。媒体元素必须显式关闭浏览器原生拖放并拦截 `dragstart`，避免对比或平移时把图片拖回画布。卡片视图销毁时必须同步关闭所属查看器，避免工作区刷新后留下脱离 Binding 生命周期的浮层。临时预览 URL、缩放和位移不写入工作流或侧边栏预设，预设只保存布局和稳定 Binding。带未知自定义 widget 或 DOM 面板的节点不做部分投影，必须通过公开 Adapter API 显式声明稳定身份、读取、写回和渲染策略；ComfyUI 在执行后注入的 `$$` 前缀不可序列化 / canvas-only pseudo widget 不是参数，不得改变同节点既有原生控件的投影资格，自身也不得成为卡片；可序列化的 `$$` 自定义 widget 仍按未知控件处理。因此新增第三方适配不会扩大或修改原生 fallback 的判断范围。

普通模式只允许切换页面、滚动、页码菜单和调参。节点右键“📌 添加参数到侧边栏…”始终可用，与编辑模式无关。编辑模式开放页面、卡片、分隔线和布局组的创建、复制、删除、网格拖动、跨页移动、宽度与紧凑样式调整；参数控件在编辑期间只读。

普通模式和布局模式都在页名之后提供紧凑的侧边栏预设选择器。每个预设同时保存全部 Dashboard 页面、分隔线、布局组、卡片网格几何、稳定 Binding 和兼容参数值；Seed 参数的保存值同时包含数值和执行后行为，因此固定、随机、递增与递减状态会随预设切换。重复投影同一 Binding 时只保存和应用一次。入口保持单行：当前状态完全匹配基准预设时显示其名称，布局或参数发生有效偏离后仍显示基准预设名称，并使用斜体和末尾 `*` 表示尚未保存；没有基准预设时显示中性占位的“选择预设”，不使用警告色。提示中说明布局和参数差异数量。弹层以选择为主操作：顶栏直接提供紧凑的“新增”按钮，不再折叠进操作菜单；悬浮或键盘聚焦条目时直接显示重命名、复制和删除三个快捷按钮；有基准的修改状态只显示“保存修改”和“放弃修改”，无基准时只显示“保存为预设”。切换、新建、保存修改、复制、重命名、删除预设成功时使用 ComfyUI 原生成功 toast 确认并附带保存工作流提醒（自动消失），不再叠加警告级提醒；失败仍走错误 toast。

切换侧边栏预设前检查当前 Working Copy：有基准时提供更新并切换、放弃并切换和取消；无基准时提供另存并切换、放弃并切换和取消。应用前按稳定 Binding、值类型和第三方 codec 完整预检，异常项进入复核列表；用户确认后保留失效卡片并应用其余兼容内容。UNet、CLIP、VAE、Checkpoint、Upscale Model 等常见模型参数若只因本机嵌套目录不同而不匹配，则按跨平台分隔符规范化后的文件名查找：仅有一个候选时列出实际路径并请求确认，确认后应用该路径；没有候选或存在多个同名候选时列出页面、组件、参数、预设模型和处理建议，但确认后仍写入预设模型值，绝不静默保留旧预设模型。布局替换和参数写入必须处于同一个图历史边界，任一写入失败时同时回滚布局与所有已写参数。预设集合和基准身份保存在 `app.graph.extra.aaaliceSidebarPresets`，参数值仍由原节点拥有；保存到预设与保存工作流是两种明确操作。

参数调整档案（Value Adjustment Profiles）是预设之外的独立全局能力：档案与规则保存在本机 localStorage（`aaalice.workspace.valueProfiles`），不进入工作流文件，因此工作流作者与最终用户各自拥有自己的档案。Dialog 只保留一条档案选择/管理栏、一个规则滚动面和 Footer 唯一主操作；档案栏显示规则数、来源数与待处理数，Footer 明示“编辑自动保存在本机、套用才修改当前侧边栏”，不制造额外的手动保存语义。规则按真实宿主来源聚合为带稳定身份色的分组，来源和页面只在组头集中展示；组内使用固定的参数名、值控件和操作列，同名参数显示组内序号，完整名称和值可通过原生 Tooltip 查看。搜索只隐藏既有分组和规则行，不重建输入；文本、选择、布尔、数值与 Seed 目标值都可直接编辑，刷新只把单条规则更新为画布当前值，移除规则需要确认。添加规则位于规则面顶栏，并用专用搜索选择面互斥替换规则面；关闭后恢复先前滚动位置，不把规则列表与候选列表同时挤在首屏。候选以侧边栏组件卡片为单位：一张多绑一卡片只出一条候选，身份取主绑定，添加候选覆盖所有页面并标注所在页面徽章，已有规则的组件不再出现。每条规则记录稳定 Binding Key、快照式目标值（与预设 `values[key].payload` 同一 codec，含 Seed 的执行后行为）以及仅用于展示和回退匹配的控件名 / 宿主标题；应用时先按 Binding Key 精确匹配，Key 失效时按控件名唯一回退，名称重复再用宿主标题消歧，仍不唯一报为歧义问题项而不猜测。命中的规则把整卡绑定（主绑定 + 全部联动目标）展开后合成单页 Dashboard 快照，复用预设的预检 / 写入 / 回滚管线，联动目标随主目标在同一事务中更新；问题项进入复核清单由用户确认后再应用可匹配部分；auto-save 开启时由既有机制收进当前预设，关闭时只改画布控件当前值。早期版本的档案级页面范围（`pages`）已移除，读取旧数据时直接丢弃。

预设捕获和应用必须尊重控件的瞬时可用性：暂不可用或未赋值的现有 Binding 在保存修改时保留原保存值，不把暂时故障误判为用户修改；真正缺失、不兼容或报错的 Binding 使当前状态显示“已修改 + 需要处理”，此时预设弹层提供警告诊断行：列出具体失效绑定（页面 · 卡片 · 失效身份，区分主参数与联动），并直达对应修复入口（主参数走重绑、联动走管理联动对话框），不得只显示状态让用户逐卡片猜测。第三方 codec 必须同步执行，写入失败时连同“已写入后才抛错”的当前项一起逆序回滚。内部快速预设与外部 JSON 备份复用同一快照、校验和预检协议；JSON 始终导出完整 Dashboard、绑定和兼容值，顶栏入口统一称为“导入预设 / 导出预设”。导出以当前下拉预设名称同时作为 JSON `name` 和下载文件名的逻辑来源，下载时只额外清理文件系统禁止字符；正常名称下文件名去掉 `.json` 后与下拉名称一致。导入默认选择“仅导入数值”，两种模式都必须输入新预设名称并额外创建预设，重名按最新预设集合追加数字后缀，绝不覆盖已有预设；仅当当前没有可复制的预设时，默认回到“布局和数值”。导入界面只保留文件摘要、导入方式、基础预设、名称、三项结果摘要和按需展开的问题项，不重复堆叠机制说明。布局模式以文件内容创建完整新预设；预检若发现 Missing、类型不兼容或解析失败的 Binding，必须提示风险并在继续前二次确认。仅数值模式选择一个基础预设，以其 Dashboard 为权威，先复制完整快照，再按去重后的 primary / linked Binding Key 精确匹配文件数值；精确身份失效时，只允许在 Provider、`valueType` 和 Control 名称一致的候选中按 Binding 锚点、稳定 Card Id、Host、页面/布局组上下文到全局同标签语义逐层恢复，并要求源目标互为唯一。禁止按页面顺序、数组下标或单一名称匹配；歧义、缺失和无效源值跳过，基础预设快照不得被修改。确认时重新解析 Provider 与 codec，把新副本持久化、切换到副本 Dashboard 和节点值写入放在同一图历史与回滚边界；成功后新副本成为当前 Dashboard 与当前基准，失败时回滚新副本、导入前 Dashboard、基准身份与已触达节点值。0.2.0 不兼容旧版纯参数预设，检测到旧集合时直接清空并提示保存工作流。

添加参数 Dialog 同时呈现目标页面与可选参数；参数区提供全选/全不选，且只作用于当前允许添加的参数。没有页面时可在同一流程创建首个页面；重复绑定默认禁用，用户可显式允许镜像卡片。页面下拉复用共享 `selectControl()`，避免宿主样式覆盖原生箭头。子图只列出子图整体对外公开的兼容参数，不进入内部图；公开的单行与多行文本都使用侧边栏文本控件，多行文本保留可纵向编辑的文本域和较高默认卡片。

“绑定到已有侧边栏参数”Dialog 只保存用户选择，不把打开 Dialog 时的 Provider 结果当作提交依据。点击确认后必须重新枚举源节点并重新匹配目标卡片，以覆盖复制子图后 Host Id 修复或公开 widget 重建；重新匹配通过后，写入 `linkedBindings` 和首次同步复用该次兼容性预检得到的 source 与目标解析快照，不在同一确认事件内做第二次 Provider 解析。节点右键菜单的“从侧边栏解绑”列出当前节点在所有页面/卡片中的绑定关系，可一次解绑一个或多个参数；解绑主参数时保留卡片并按联动顺序提升下一个主参数，单参数卡片才随解绑被移除。布尔 `false` 是合法读取值，不能按 Provider 操作失败返回处理；只有写入、回滚和冲刷等操作返回 `false` 才表示失败。失败时保留 Dialog 和原 Dashboard，不显示伪成功。

Dashboard V4 持久化十二列细分逻辑网格而非像素位置；卡片宽度为 3–12 的任意整数列跨度，行高为不小于 13 的任意整数跨度，默认半宽六列等推荐值不构成尺寸目录。窄侧栏只投影为单列，不回写规范宽度；Provider 的非持久 `layoutProjection` 与布局组单列投影都通过通用矩形投影重新计算页面及组内显示占位，不得裁掉成员或覆盖 `data-drop-*` 和规范布局。卡片不可重叠；拖拽落点发生碰撞时，本次拖动的卡片、框选整体或布局组必须保留用户指定的落点，原位置相交的布局项按稳定视觉顺序向下挤开，并只继续推动同一碰撞链，不能把拖动项自动退回页面底部。缩放发生碰撞时仍只让本次缩放项顺延到最近可用行，不改动其它布局项及既有空隙。“整理布局”只由用户显式触发，并按稳定视觉顺序确定性紧凑排列完整矩形占位，重复执行结果不变。拖拽、键盘和命令统一吸附整数网格。框选后的整体拖动以同一网格作用域内的选区包围盒吸附，原子提交全部成员的新坐标并保持内部相对布局，不允许选中项互相触发碰撞整理；当选区同时包含页面散项和一个或多个布局组成员时，组成员提升为对应完整 Layout Group 参与根网格拖动，成员关系和组内相对坐标不得被清除，解除分组只能走显式操作。Layout Group 组内复用同一细粒度网格；打组时把成员的页面坐标转换为组内相对坐标，并让新组占据选区原来的左上位置；新增的组标题和外壳若与后续页面项碰撞，只把相交项及其碰撞链向下挤开，不得把新组追加到页面末尾。布局模式下，散项或其它组成员拖入现有组的标题、边缘或内容区域时，整个组合卡片进入明确的“加入组”接收态；松手后把条目按稳定顺序放入目标组的首个可用位置，目标组保持原锚点，其扩大占位只向下推动相交的页面项及碰撞链。拖回原组内部仍按网格精确移动，整组不得嵌套；原组失去最后一个成员时自动移除空外壳。解除整组时再把成员还原为页面坐标，不隐式整理其它布局项。组的外部占位由组内内容确定，组不嵌套、不折叠。V2/V3 自动迁移为 V4；V2 旧双列的列位置与列跨度等比映射到十二列，原有有效整数行跨度保留。

Layout Group 的视觉层是一张组合卡片，而不是外框内再堆多张完整卡片。成员控件常态取消独立边框和投影，使用统一中性背景融入组合外壳，同时继续作为可单独选择、移动、缩放和解绑的布局项。布局模式下，页面散项、组内成员和分隔项只要进入同一个选区，都必须立即显示同样清晰且不改变占位的强调色选择轮廓；组内成员仍保留单侧成员标记，不能因为组合卡片的高优先级样式把当前项的选择轮廓覆盖掉。该组合语义由 Dashboard 视图层统一添加，Control Renderer 不感知成员是否位于组内。

## 词库与导入导出

词库工作区提供搜索、分类、收藏夹、标签、词条编辑、单张预览图和完整/筛选导出。已选操作栏固定承载移动、导出、危险确认删除与全选/全不选；导出作用于当前已选词条，批量删除必须保持事务原子性。默认收藏夹始终存在且不可删除；PromptSelector 的收藏按钮从词库快照派生状态，收藏时选择目标收藏夹，取消收藏时移除该词条的全部收藏关系。导入必须先显示新增、已有、冲突、重复和无效数据，再由用户为冲突选择保留本地、使用导入或创建副本。

词库 ZIP 只上传一次并暂存到服务端，确认后使用 token 应用；导入、解压与导出上限为 2 GiB，上传、解压和下载均避免整包驻留内存。Dashboard 预设备份单独导入导出；完整模式保留 Missing Binding 并允许人工重绑，仅数值模式只把可安全匹配的值套用到基础预设副本。

## 性能与生命周期

- 主词库和 PromptSelector 共用快照级索引、定高虚拟列表与图片预览服务，不分别维护派生数据和监听器。
- DOM 行数只随可视区域与少量 overscan 变化，不随词条总数线性增长；筛选只替换索引结果，不为每条词条注册常驻观察器。
- 图片使用惰性加载；大图预览复用单例浮层，锚点离开、条目重用或视图销毁时必须清理当前预览。
- 词库事件按受影响范围刷新。图变化和连续输入合并更新，不使用轮询，也不在每个按键后重建整个工作区。
- Dialog、Popover、文件输入、全局事件和 `AbortController` 在所属视图销毁时释放；仍有效的焦点和操作状态不得因局部刷新丢失。每个可见侧栏根按 Dashboard Page Id 独立记住会话滚动位置；删除卡片、拖拽提交或其它结构重绘必须在替换 DOM 前记录并在新 Scroll Surface 挂载后恢复，不能回到页面顶部。切换页面后恢复该页面上次位置，加载另一工作流时清空旧图的滚动记忆。
- 画布上的紫色参数轮廓由 Dashboard Binding 派生，只投影到当前可见 graph。普通节点与 Subgraph 公开参数使用同一套标识语义；进入或退出 Subgraph 时监听宿主 `litegraph:set-graph` 事件，失效公开 widget 结构缓存并重新同步。Nodes 2.0 的 DOM 行匹配不得要求原始 `node.widgets` 与宿主最终渲染行数量完全相等；`preview_text`、canvas image preview、动态显隐或宿主去重只能跳过对应特殊组件，不能清除同一节点上其它已绑定参数的紫框。无法唯一确认的行保持不标记，不得按裸 Node Id、模糊顺序或轮询猜测。

## 交互与可访问性

- 内容区自然竖向滚动且只作用于当前页面；当前页标题旁的紧凑页码入口显示当前序号与总页数，点击或键盘激活后打开完整页面菜单。菜单中的整行可选择页面，专用排序手柄位于条目开头，并提供 `Alt+ArrowUp` / `Alt+ArrowDown` 键盘排序；当前项保留 `aria-current`。右侧 Page Rail 在 Dashboard body 中占用独立的 38px 圆点列，不遮挡页面 Scroll Surface 或卡片；收起态只有圆点簇中央的动态命中区响应悬停，圆点上下两侧的空白不触发展开；悬停或键盘聚焦时胶囊可向内容侧展开为名称胶囊，展开后的透明命中区覆盖胶囊之间的间隙，只有离开整个展开包络才收回，选中胶囊使用强调色光晕。Rail 内只通过点击和键盘直接切换相邻页面，滚轮不参与页面切换。页面内容到达上下边界、内容不足一屏或快速滚动都不得隐式切换页面；页面重挂不保留未完成的页面切换意图。
- 拖动只在编辑模式启用；普通调参不会误改布局。布局模式的整个 Dashboard 空白表面都可起框；普通按下任意卡片会先选择它并保留直接拖动，只有 `Ctrl` / `Meta` / `Shift` / `Alt` 修饰手势才从卡片进入加选或减选框选，按钮、输入和缩放手柄仍执行自身操作，因此密集页面不要求寻找卡片缝隙。完整命中的 Layout Group 是一个根级选择单元，其成员仍显示同层选择轮廓，禁止因成员从散项集合移除而出现选区末尾视觉掉选。拖拽预览必须同时显示吸附后的选区占位、明确的前缘插入标记和将被稳定下推的碰撞链；进入其它组时继续保留位置预览，并额外显示整组接收态与居中“加入组”徽标。指针接近 Scroll Surface 上下边缘时使用单个动画帧循环连续滚动并重算框选/落点，离开、松手或 `Escape` 立即停止并清除全部临时位移。`Alt`+方向键按规范十二列网格移动当前选择，`Shift` 加速为两个单位；普通方向键仍只负责卡片焦点导航。全选只通过顶栏“全选布局项”按钮触发，不注册 `Ctrl` / `Meta` + `A`；该按键在侧边栏非文本区域被消费，文本输入仍保留原生全选，均不得传给 ComfyUI 画布。
- 颜色使用 ComfyUI token；错误、缺失、禁用和选中状态同时提供文字或形态信息。
- Dialog、文件输入、列表复选框和纯图标按钮必须具备可访问名称；销毁工作区时清理监听器和挂载内容。

## 视觉层级

- 工作区使用紧凑品牌头、双工作区分段导航、页面导航、可选布局组和参数卡片建立层次；没有组时不显示额外标题。当前 Dashboard Page 使用带页码索引、主题强调色和明确字号层级的紧凑页面标题区，与预设及布局操作保持同排；页名支持双击或 `Enter` / `F2` 原位重命名，输入期间保留标题区和相邻操作的尺寸。页面空白处右键菜单统一承载重命名、复制、页面颜色和删除，布局模式下追加分隔线与整理布局。
- “布局”是低频结构模式入口：普通态使用弱化的无边框按钮，不与参数调节争夺视觉焦点；进入编辑模式后才以柔和强调底色显示“完成”，同时呈现页面、网格、布局组和卡片管理操作。
- 参数卡片不常驻设置或布局按钮；右键、`ContextMenu` 或 `Shift+F10` 打开共享上下文菜单。普通模式提供重绑与移除，布局编辑模式再追加移动、宽度和紧凑度操作；文本输入区域保留浏览器原生编辑菜单。参数值始终比管理操作更醒目。节点右键菜单在存在侧边栏绑定时提供“从侧边栏解绑”，从当前节点绑定的参数列表中选择目标；解绑主参数时优先提升同一卡片的下一个联动参数，只有最后一个参数被解绑时才移除该卡片。
- 每张参数卡片与分隔项的右键菜单都提供组件说明。说明编辑器保持单标题、单内容面的紧凑结构，用一个 Switch 在 Markdown 源码编辑和安全 CommonMark/GFM 预览间切换，并提供粗体、斜体、删除线、标题、引用、列表、任务列表、行内/块代码、链接、图片、表格和分隔线等常用格式入口；键盘至少支持 `Ctrl` / `Cmd` + `B`、`I`、`K` 与 `Shift+X`。保存后只在标题旁显示低强度信息徽章，悬浮只说明“点击查看完整说明”，点击打开完整预览，禁止把整段说明绑定到卡片或标题的普通悬浮而遮挡调参视野。徽章始终有可访问名称，窄卡片、Header-only 卡片、联动数量徽标和分隔项删除按钮共存时不得重叠或改变卡片占位。
- Seed 与其它无有效范围的数字只占用卡片标题行，数值和执行后行为按钮保持同一基线；网格使用内容高度而非同行最大卡片高度，不能因为邻近滑条而留下空白下半区。
- 每张参数卡片都是只影响派生视图的尺寸查询边界，规范 `rowSpan` / `columnSpan` 仍是唯一持久几何。多行文本、Markdown、执行输出和复合列表占满标题下的剩余空间并在不足时内部滚动；标签卡片由矮态单行滚动切换为高态换行；窄而较高的分段选择改为多行，图像选择在高卡片中扩大预览。单行输入、布尔和数值控件保持可读的最大高度并在多余空间内居中，禁止把 32px 控件机械拉成整卡高度。所有变化由 CSS Container Query 驱动，不为每张卡片安装 `ResizeObserver`、不写回 Dashboard，也不在拖拽帧重建控件 DOM。
- 数值控件使用“范围 + 精确值”的心智模型：适合范围调节的有界数值使用紧凑滑条与可点击数值，Seed 和无可靠范围的数字只显示精确值，避免无意义滑条；普通 Integer / Float 卡片的右键菜单提供“设置数值范围”，可为该卡片单独设置最小值、最大值和步长或恢复节点默认值。该设置随 Dashboard、页面复制和侧边栏预设保存，只改变侧边栏投影，不修改节点参数定义或自动改写当前值；自定义边界不得越过节点声明范围，Integer 的三个值必须都是整数。Seed 同时复用四模式行为按钮，通过 Popover 选择 `fixed`、`increment`、`decrement` 或 `randomize`，并与来源 widget 保持同一状态真源。点击数值进入精确编辑，控件区域滚轮和方向键按 step 调整，按住 `Shift` 以十倍步长快速调整。一次连续拖动或滚轮手势只形成一个图历史边界。
- 枚举和布尔参数分别复用共享 `selectControl()` 与 `toggleSwitch()`；图像参数复用同一个 32px 图像控件、上传链路、拖放反馈、即时完整预览和清空交互，侧边栏只映射主题 token，不另造一套表现。文本、其它文件和缺失绑定保留清晰的输入或修复入口，不用相同外形伪装成滑条。
- 每张参数卡片的标题前统一显示紧凑的类型色标识；数值、Seed、布尔、枚举、文本、标签、图像、Markdown、执行输出与组管理等现有控件类型使用稳定且彼此可区分的主题色，未知第三方类型回退到当前主题强调色，页面识别色不得覆盖类型色。该标识只帮助快速扫读，控件名称仍是类型与身份的主要信息；Missing Binding、不可用和 Seed 执行后行为等语义状态继续通过背景、图标或文字明确表达。
- Layout Group 标题不复用参数卡片的前置类型色条；组名使用组识别色的紧凑无边框胶囊铭牌，与组外壳形成清晰层级。铭牌只包裹标题文本，长标题截断，右侧同步、拖拽和设置操作保持稳定，不因标题显隐或悬浮改变尺寸。
- `PreviewAny` 卡片的参数名称与“纯文本”/“Markdown”模式徽标共用卡片标题行，模式靠右且不挤压长标题；正文区域只承载预览内容，不为单个状态徽标额外占用一行。
- PromptSelector 以条目选中表面、分类短标签和底部数量摘要提高扫读效率，不在 DOM overlay 上复制节点外壳。
- 页码入口与页面标题保持同排，只占用显示当前序号、总页数和方向箭头所需的紧凑宽度，不覆盖内容。页面菜单使用低强度浮层列出全部页面；排序手柄、序号、名称和当前状态保持稳定列对齐，长名称截断但完整文案可访问。页面切换采用 180 ms 内的克制纵向过渡，不能用延迟、弹跳或悬浮重开阻塞输入，并遵循 reduced-motion 设置。
