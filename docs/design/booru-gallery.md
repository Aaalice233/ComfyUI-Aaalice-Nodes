# Booru Gallery 设计规范

## 目标

`BooruGalleryNode` 是 Danbooru、Gelbooru、Safebooru 与 AI TAG 的多站点图片检索、浏览、选择和本地 Prompt 整理节点。节点保持真正的自然比例瀑布流；账户、站点差异和网络状态不改变主浏览结构。

界面定位为紧凑的图片工作台，而不是网站缩略版。视觉层级依次为图片内容、当前选择、来源与筛选、辅助元数据；节点强调色只用于选择、焦点和主操作。表面保持克制，依靠自然图片、留白、细边框和轻量浮层建立层次，不重复绘制节点外壳。

四个来源各自拥有稳定的来源识别色（Danbooru 蓝、Gelbooru 青、Safebooru 绿、AI TAG 紫），通过 `--aa-gallery-source-tone` 提供给已选列表行、详情与编辑的来源徽章以及设置页的来源 Tab。来源识别色只表达来源身份，不表达状态；选中、焦点等状态继续使用节点强调色，两者共存时身份色只占小幅表面。来源徽章使用胶囊形态与字距拉开与正文标签的层级。

## 单行顶栏

节点始终只有一条顶栏，顺序为来源、浏览/已选 Switcher、弹性空白、频道选择、当前页操作组、刷新、设置和搜索。频道选择必须直接暴露站点提供的最新、高分榜、人气榜、随机、今日榜、周榜、月榜和收藏夹，不把这些入口藏进筛选设置；不支持的频道不显示。频道触发器与浮层选项使用共享 Listbox 的前置语义图标，选中勾仍只表达当前值，不能拿同一个图标同时表达频道类型和选中状态。浏览/已选属于两个不同业务阶段，Switcher 必须使用不同语义色：浏览为信息蓝，已选为完成绿；颜色随滑动 thumb、激活文字和焦点反馈一起切换，同时保留位置、文案、滑动动画与 `aria-checked`，不能只靠颜色表达状态。Switcher 不显示已选数量、角标或胶囊；数量只在已选页内容区说明，避免破坏两个页签的视觉平衡。当前页操作必须使用“图标 + 短标签”：漏斗只表示帖子筛选，标签图标只表示提示词处理；齿轮只用于打开 ComfyUI 内置设置。刷新与设置必须作为顶栏中的独立图标按钮直接可见，不藏进省略号菜单；刷新请求期间按钮进入禁用的“正在刷新”状态，刷新图标持续旋转，结束或失败后恢复。设置按钮优先调用 ComfyUI 的设置命令；命令不可用时才用可见提示说明“左下角齿轮 → Aaalice Nodes → Booru Gallery”的操作路径。窄宽度下可以隐藏短标签，但不得复用相同图标表达不同职责。来源、频道、排序和设置中的默认来源统一使用共享 `listboxControl()`，由 DOM 绘制圆角触发器和浮层选项，不使用浏览器原生 `select` 外观。搜索展开时在同一行占用弹性空间并隐藏当前页操作组、刷新和设置，不增加第二条工具栏。搜索 input 始终复用同一 DOM identity，保证焦点、选区、IME 和第三方输入插件正常工作。

## 筛选与提示词浮层

- 两个浮层共享同一工具面板结构：带语义图标、标题、说明和上下文标签的紧凑 Header，中部使用有边界但低对比的功能分区，底部集中显示应用方式或主操作。不得继续使用松散的单列字段堆叠。
- 筛选浮层在同一行并列展示 Rating 与排序。Rating 选项使用两列可扫描选择块，并实时显示已选数量；排序保留完整的共享美化下拉框。应用按钮固定在 Footer 右侧，并明确说明刷新不会影响当前选择。
- 提示词浮层优先利用横向空间：类别使用三列选择矩阵；格式转换与排除标签在下方并列。每个转换项同时显示名称和结果说明，排除标签提供可理解的示例占位。Footer 明确提示修改自动应用，不伪造保存按钮。
- 浮层宽度分别以约 420px 和 480px 为基准，同时受视口宽度约束；窄视口下自动改为单列。所有文字、控件和焦点状态必须在暗色与亮色主题中可读，动效遵循共享 reduced-motion 规则。

## 浏览与选择

- 浏览页使用自然宽高比虚拟瀑布流。卡片按最短列放置，同高时优先左列。
- 来源频道只展示适配器明确支持的内容：Danbooru 提供今日榜、周榜与月榜，AI TAG 提供月榜；Gelbooru、Safebooru 不从局部搜索结果伪造排行榜。顶栏使用紧凑“第 N 页”控件，点击后才展开上一页、下一页和页码输入，不另起第二条分页栏。瀑布流跨过分页边界时同步当前逻辑页；刷新保留该页，来源、查询、筛选或频道变化回到第 1 页，直接跳页不加载前面的结果。
- 卡片默认只保留图片、右上角 Rating 标签和已选时的左上角顺序号，卡片圆角保持克制，不超过 8px。帖子来源、ID 与分辨率默认隐藏，悬停或键盘聚焦后才随底部渐变淡入；Rating 使用 Safe / Sensitive / Questionable / Explicit 各自的语义色标签。
- Gallery 当前只支持可进入工作流的 JPG、JPEG、PNG、WebP 与 GIF；MP4、WebM 等视频必须由来源适配器在帖子进入瀑布流前过滤，禁止展示无法选择的卡片。
- 点击图片主体直接在“选择图片 / 取消选择”之间切换，不再打开详情，悬浮操作组不得重复提供选择按钮。编辑本地标签、能力允许的收藏和查看详情位于右上角悬浮操作组；每项使用独立语义色，并通过错峰淡入、位移和悬停提升建立动作层级。指针点击造成的焦点不得让操作组在离开卡片后滞留；键盘 `focus-visible` 仍能展开操作。悬停时 Rating 标签暂时淡出，为操作组让位，收藏失败回滚原状态。
- 帖子被选中后，图片只覆盖低不透明度的轻量压暗层，不能让原图失去色彩和主体辨识。中央使用不超过 34px 的勾选标记，输出顺序作为独立的小型角标贴在标记右下方，避免把勾选和数字挤进一个过大的实心圆；蒙层不得使用高成本的逐卡片模糊，未选中时不占用卡片角落。
- 操作组按卡片自然比例自适应：横图横排、竖图竖排、接近方形时两列混排。卡片最小宽度下的横排尺寸必须完整容纳当前来源的全部操作按钮；响应式只使用帖子比例数据，不为卡片增加容器查询或 ResizeObserver。
- 站点声明收藏读取或写入能力时，卡片和详情始终显示收藏按钮，不能因为本机尚未配置凭据而隐藏入口。支持写入但缺少凭据时，点击按钮显示账户说明并提供打开 Gallery 设置的主操作，不发送注定失败的网络请求；仅支持读取时明确说明当前为只读。完全不支持账户收藏的来源不显示按钮，不能伪装成登录后可用。
- 滚动只挂载视口及上下 0.75 个视口内的卡片；图片离开范围时立即释放 `src`。
- 卡片显示有序选择编号。详情只在悬停、打开或选择时按需请求，搜索页不逐帖补全标签。
- 指针稳定悬浮后显示节点外的大图预览卡。预览参照 `Aaalice_NAI_Launcher` 的 Gallery 悬浮层：优先出现在卡片右侧，空间不足时翻到左侧；宽度不超过 320px，图片按自然比例计算高度并限制在 150–420px。先用已缓存缩略图立即占位，再按需获取 Detail，并只替换为站点 Sample / Large Preview，禁止为一次悬浮下载原图。较大预览仍在请求或解码时，图片右上角显示小型半透明旋转图标；图标不得附带胶囊文案、遮挡主体或在缩略图刚加载后提前消失。来源与帖子 ID、内联元数据、Rating 以及 Artist / Character / Copyright 摘要必须压缩为图片底部的渐变信息层，不额外增加独立底栏高度；三类标签使用同一行并各自截断。不使用四宫格数据卡、原始日期和操作提示尾注。指针离开、卡片卸载或当前 Tooltip 已切换时，迟到的 Detail 不得重新显示或更新旧预览。
- 选中页使用定高虚拟列表。顶部同时说明输出对数；每行依次显示拖动抓点、顺序号、缩略图、来源与格式、图片元数据与最终 Prompt 摘要。顺序就是 `images` 与 `prompts` 的输出顺序；仅拖动抓点可重排。
- 点击文字区直接打开帖子详情，并复用详情中的标签编辑、搜索与黑名单操作；删除按钮仅在行悬停或键盘聚焦时淡入，不常驻占用布局。
- 拖动重排时显示节点强调色插入位置线：根据指针在目标行上半/下半区判断插入到该行之前或之后，两端带圆点的固定定位横线标出落点；被拖动行走半透明虚线边框。原位无效落点不显示指示线。拖出列表、结束拖动、切换视图或完成放置后清理指示状态。
- 已选行只在悬停缩略图时复用浏览页大图预览卡（受“显示悬停详情”设置控制，先缩略图占位再按需拉取 Sample）。右侧文字区不再创建独立 Prompt 浮层，点击或键盘激活时直接打开帖子详情，所有标签编辑、加入搜索和黑名单操作均复用详情实现。滚动列表、拖动重排、切换视图或行卸载时关闭图片预览。
- 空选择使用居中的轻量引导，不保留虚假的列表卡片或大面积装饰。
- 搜索错误保留选择；分页错误保留已有瀑布流；收藏失败回滚本次按钮状态。
- 全局内容黑名单按网站原始标签精确匹配，并在帖子进入卡片集合前生效；搜索、排行榜和收藏夹使用同一规则。传统 Booru 由适配器同时生成远端排除查询并校验列表响应，AI TAG 直接使用列表响应携带的 `tags` 过滤，禁止为黑名单逐帖加载 Detail。从详情快捷加入黑名单时，所有 Gallery 节点立即刷新，并移除既有选择中包含该标签的帖子；节点不显示“已屏蔽”占位。黑名单不改变其余帖子的最终 Prompt。
- 加载、到底和错误状态必须同时显示语义图标与文字；`hidden` 或空状态不得留下无文案胶囊。瀑布流只允许纵向滚动，不显示横向滚动条。

## 微动效与精致度

动效只服务于状态确认、空间来源和可操作性，不持续占用主线程：搜索框从右侧原位展开；浏览/已选切换以同一 thumb 的弹性滑动和内容轻微淡入建立方向；选择或取消时卡片边缘只播放一次绿/红确认环，数量文本同步轻弹；收藏成功只让收藏按钮短促回弹。图片卡片悬浮时由内部 Surface 抬升并增强阴影，根据指针在卡片内的位置产生不超过约 4° 的双轴倾斜，同时让径向高光与斜向光带跟随指针扫过；瀑布流负责定位的卡片根元素不得参与倾斜。悬浮按钮错峰展开，已选行、详情事实块和设置卡片只做 1–2px 抬升与轻微表面变化。标签数量仅在实际变化时轻弹，恢复原始标签必须同步刷新数量。

所有动效使用主题 token、`transform` 与 `opacity` 为主，单次约 140–340ms，不给每张卡片增加观察器或常驻动画；指针移动只在单个 `requestAnimationFrame` 中合并更新 CSS 变量，卡片离开虚拟范围时必须取消待处理帧和监听器。节点宽度改变导致列数或最短列归属变化时，已挂载卡片必须通过位置 `transform` 平滑迁移到新列，不得瞬移；滚动和初次挂载不会触发卡片入场动画。`prefers-reduced-motion: reduce` 下关闭 Gallery、详情、编辑和设置中的动画及过渡，并停止指针倾斜计算。

## 详情与本地编辑

详情 Dialog 使用“原图舞台 + 信息检查器”双栏结构：左侧尽可能完整显示真实图片，右侧集中展示来源、帖子身份、尺寸、格式、Rating 和五类标签；窄窗口自动变为上下结构。检查器采用层叠工具盘语言：身份、事实数据和标签类别分别落在无边框的错层表面上，通过圆角、间距与定向柔影建立层级，禁止用连续横线或竖线切割。事实数据使用紧凑微型仪表块；标签类别使用中性浮层，类别色只出现在识别点、标签和极轻阴影中，避免彩色边框与彩色背景叠加成大色块。胶囊不常驻操作图标，右键菜单提供“编辑”和“屏蔽标签”：编辑在原位展开输入框并保存为当前帖子本地修改，屏蔽则加入唯一全局黑名单、关闭详情并从所有 Gallery 节点隐藏含该标签的帖子。左键不触发屏蔽。Footer 提供原站、代理原图、选择及 capability 允许的收藏操作。

本地标签编辑以真实缩略图和本地修改说明开场，Artist、Copyright、Character、General、Meta 五类分别使用带实时数量的胶囊编辑区。胶囊与已选 Prompt 悬浮卡共享类别色和单击编辑、右键删除语义；末尾只常驻一个加号胶囊，点击后原位展开输入框，支持逗号、中文逗号与回车批量添加，完成、取消或空内容失焦后收回。允许增删、恢复和复制 Prompt。只有已选快照进入工作流；不修改远端帖子。

筛选 Popover 先说明当前来源，再显示该来源实际支持的 Rating 与排序；无 Rating 能力时显示明确说明而不是空控件。Prompt Popover 明确说明输出按已选顺序生成，并把类别、转换选项和精确排除标签分成三个阅读区。

## 设置

ComfyUI Settings 中只有一个 `Booru Gallery` 入口。设置 Dialog 使用同一个四段导航切换“账户 / 浏览 / 提示词 / 存储”，避免把所有表单一次堆进长页面。Dialog 标题和当前导航已经明确页面身份时，不再为各页固定增加副标题；只有影响风险理解或功能边界的说明才放在对应操作附近：

- 每个来源卡片显示稳定来源身份、已配置 / 未配置 / 公开访问状态、实际能力、凭据、默认 Rating、连接测试及局部状态；凭据清除使用紧凑图标动作，连接测试使用旋转、成功和失败三种反馈。
- 浏览页只包含默认来源、内容黑名单和 Tooltip；黑名单使用独立的内容保护卡，显示实时标签数量、作用范围和“隐藏帖子而非修改 Prompt”的边界。Prompt 页只影响新节点；存储页集中管理超时、缓存预算和带说明的缓存清理危险操作。
- 四个页面共享稳定内容区域，切换时只做短促淡入位移；表单、测试状态和已输入凭据 DOM 不因切页重建。
- API Key、用户 ID、用户名和缓存不进入工作流；节点更多菜单只打开同一设置 Dialog。
- “排除标签”只有一份全局真源：当前 ComfyUI 用户目录中的 Gallery 内容黑名单。详情页快捷屏蔽、提示词处理浮层的排除标签输入框和 Gallery 设置页必须读写同一列表；列表中的标签既会隐藏包含它的帖子，也会从已有选择的输出 Prompt 中排除。所有画廊节点、来源和工作流共用该列表，切换、新建或加载其他工作流不会清空；旧版 `promptDefaults.excludedTags` 在读取时合并进黑名单并清空，不保留第二套状态。

## 尺寸与双模式

默认尺寸约 760×720，稳定内容下限为 620×300。`computeSize()` 与 `onResize()` 共同约束宽度，避免工具栏和条目操作区被压缩到失效；高度下限与当前节点高度无关，禁止把已经拉高的几何重新写成最小高度。节点缩短时只让瀑布流或已选列表内部滚动，ResizeObserver 只观察瀑布流容器。

DOM widget wrapper 与 Gallery 根不接收指针；只给顶栏控件、瀑布流滚动区和已选列表开启命中。内容在底部保留 13px 安全带，并在左右各留 10px，使左下角和右下角都直接落到 LiteGraph 原生 resize 命中区。进入原生 resize 手势后，Gallery 根及全部后代立即关闭命中。Classic 与 Nodes 2.0 共用内容结构，标题、socket、节点拖拽和缩放继续由 ComfyUI 管理。
