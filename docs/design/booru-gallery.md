# Booru Gallery 设计规范

## 目标

`BooruGalleryNode` 是 Danbooru、Gelbooru、Safebooru 与 AI TAG 的多站点图片检索、浏览、选择和本地 Prompt 整理节点。节点保持真正的自然比例瀑布流；账户、站点差异和网络状态不改变主浏览结构。

界面定位为紧凑的图片工作台，而不是网站缩略版。视觉层级依次为图片内容、当前选择、来源与筛选、辅助元数据；节点强调色只用于选择、焦点和主操作。表面保持克制，依靠自然图片、留白、细边框和轻量浮层建立层次，不重复绘制节点外壳。

四个来源各自拥有稳定的来源识别色（Danbooru 蓝、Gelbooru 青、Safebooru 绿、AI TAG 紫），通过 `--aa-gallery-source-tone` 提供给已选列表行、详情与编辑的来源徽章以及设置页的来源 Tab。来源识别色只表达来源身份，不表达状态；选中、焦点等状态继续使用节点强调色，两者共存时身份色只占小幅表面。来源徽章使用胶囊形态与字距拉开与正文标签的层级。

## 节点与 Dashboard 投影

Gallery 节点 DOM 与 Dashboard 卡片是同一个节点运行时的两个投影，不是主界面与简化副本。运行时唯一拥有请求、分页游标、结果集合与错误状态；`node.properties` 唯一拥有工作流持久状态。任一投影修改来源、查询、频道、筛选、随机模式、浏览/已选视图、选择模式、已选集合、顺序或本地标签后，控制器必须定向同步所有已挂载投影；同一节点无论挂载多少 Dashboard 视图都不得重复发起请求。投影销毁只释放自己的 DOM、虚拟列表和观察器，节点移除才销毁共享控制器。

Dashboard 使用完整工具栏、瀑布流、已选列表、详情与设置能力，并额外用单个“图标 + 当前状态”徽章显示该节点的启用 / 静音 / 绕过状态。窄侧边栏把顶栏收敛为两条紧凑语义带：第一行合并来源、浏览 / 已选、单选 / 多选与收起搜索；两个 Switcher 启用共享 `segmentedControl({ activeLabelOnly: true })` 收缩契约，当前项显示图标与文字，未选项仅显示图标，节点投影和未启用该选项的其它 Switcher 不受影响。筛选、提示词、随机、刷新、清空与设置等明确工具操作只显示图标并保留本地化 Tooltip；搜索默认收起，点击搜索图标后在原位展开。Dashboard 瀑布流采用更小的卡片宽度，在常用窄侧栏宽度下优先保持至少三列；节点投影仍保留较大的阅读尺寸。状态徽章只读且不写入节点 `mode`；节点模式由节点自身或宿主菜单修改后，通过 `node:property:changed` 事件同步 Classic、Nodes 2.0 和其它投影，不得通过 `app.graph`、当前画布或裸 Node Id 反查。Gallery 不允许与其它参数联动，但作为整体参数参与 Dashboard 值预设：预设通过版本化 codec 深拷贝完整 `booruGalleryState`，覆盖来源、查询、频道/排序/分级、页码、随机模式、浏览/已选视图、单选/多选、提示词规则、已选集合/顺序/本地标签，以及 Dashboard 搜索框的展开/收起状态；切换预设后同步全部已挂载投影并按恢复条件重新请求。搜索结果、滚动像素、加载/错误、Hover、Popover/Dialog 和随机已见集合仍是会话派生状态。布局同时随 Dashboard 预设保存。当页面只有一个未分组 Gallery 时，其高度临时投影为 Dashboard 可用视口高度，普通模式与布局模式共用同一投影，切换模式不得回退到持久默认高度造成卡片缩短；投影不改写预设中的规范行跨度。

## 双行上下文工具栏

节点使用一个包含两条语义行的上下文工具栏。第一行固定为来源、浏览/已选 Switcher、单选/多选 Switcher、弹性空白和搜索；来源选择器以地球图标明确站点语义。第二行随当前视图变化：浏览状态展示频道、页码、筛选、提示词、随机模式、刷新和设置，已选状态展示有序输出摘要、清空与设置。选择模式属于工作流状态并默认为单选：单选时选择新图片直接替换旧图片；用户切换后的单选或多选值必须立即写入 `node.properties`、标记工作流变更，并在刷新或重新加载后恢复；从多选切为单选且已有多张图片时，必须确认后只保留第一张输出。频道选择必须直接暴露站点提供的最新、高分榜、人气榜、今日榜、周榜、月榜和收藏夹，不把这些入口藏进筛选设置；不支持的频道不显示。频道触发器与浮层选项使用共享 Listbox 的前置语义图标，选中勾仍只表达当前值，不能拿同一个图标同时表达频道类型和选中状态。浏览/已选属于两个不同业务阶段，Switcher 必须使用不同语义色：浏览为信息蓝，已选为完成绿；颜色随滑动 thumb、激活文字和焦点反馈一起切换，同时保留位置、文案、滑动动画与 `aria-checked`，不能只靠颜色表达状态。“已选”文字后显示单个数量数字，使用无边框 tonal 背景、定向柔影和内侧高光建立层次，禁止用描边或 `0 0 0 1px` 阴影模拟圆环。当前页操作必须使用“图标 + 短标签”：漏斗只表示帖子筛选，标签图标只表示提示词处理；齿轮只用于打开 ComfyUI 内置设置。刷新、清空与设置在默认宽度都使用“图标 + 短标签”直接显示，窄宽度下才收回文字，三者都不得藏进省略号菜单。随机模式使用紧邻刷新按钮的独立 Switcher：关闭时保持中性低强度表面，开启时使用紫色身份面、明亮滑块、发光边缘和 `aria-checked` 共同表达状态；不再添加重复的底部提示。开启后刷新按钮改用洗牌图标与“再抽一组”，抽取期间使用旋转加载图标与“抽取中”，结束或失败后恢复；普通模式仍显示刷新图标与“刷新 / 正在刷新”。设置按钮优先调用 ComfyUI 的设置命令；命令不可用时才用可见提示说明“左下角齿轮 → Aaalice Nodes → Booru Gallery”的操作路径。窄宽度下可以隐藏短标签，但不得复用相同图标表达不同职责。来源、频道、排序和设置中的默认来源统一使用共享 `listboxControl()`，由 DOM 绘制圆角触发器和浮层选项，不使用浏览器原生 `select` 外观。搜索通过组件的 `defaultOpen` 默认展开，在第一行占用弹性空间并保留固定控件与第二行上下文操作，不生成第三条工具栏；初始化展开不得抢夺焦点，用户仍可通过尾部箭头收起。搜索 input 始终复用同一 DOM identity，保证焦点、选区、IME 和第三方输入插件正常工作。搜索框通过 `data-autocomplete-plus` 属性接入 Autocomplete-Plus 的标签与中文补全；候选面板打开期间输入框带有 `data-autocomplete-plus-open`，搜索框自身的 Enter 提交与 Esc 收起在该期间整体让位给补全面板，插件未安装时行为不变。提示词处理浮层与画廊设置中的排除标签 / 输出过滤文本域、详情标签的编辑与新增输入框同样声明该 opt-in；标签编辑输入框在候选面板打开期间让位按键与失焦提交，等插件关闭面板并写入最终文本后再保存。未提交的查询在焦点离开输入框时自动确认执行搜索过滤（补全候选面板与 IME 组合中的失焦属于编辑延续，不触发）；清空搜索内容必须立即提交空查询、回到第 1 页并刷新画廊；收起搜索框时若输入值尚未提交，必须先提交并刷新再折叠，禁止让旧查询在重载后复现。

## 筛选与提示词浮层

新节点的分级固定为当前站点的全年龄等价项；设置页不提供“节点初始分级”。节点内每次勾选立即写入 `node.properties` 并标记工作流变更，应用按钮只负责按已保存分级刷新结果。

分级过滤作用于当前来源的搜索、日榜、周榜和月榜；切换排行榜不得丢弃已选分级，在排行榜内应用过滤也不得擅自切回普通搜索。排行榜接口不支持远端分级参数时，由服务层对同一页 Summary 做精确分级过滤，且分级必须进入缓存键。

来源、查询、浏览频道、排序、分级、逻辑页码、随机模式、浏览/已选视图、提示词规则、已选帖子顺序和已选帖子的本地标签编辑都属于工作流状态。`onConfigure` 可做早期同步，但 `loadedGraphNode` 才是加载恢复的最终边界：此时必须从 `node.properties` 再同步所有对应控件并按恢复后的状态重新请求；加载期间的初始化请求不得覆盖恢复请求。Dashboard 搜索框展开/收起属于节点所拥有的 Dashboard 投影状态，写入 `booruGalleryState.dashboard`，并进入包含该 Gallery 卡片的 Dashboard 值预设；同一节点被多张 Dashboard 卡片投影时共同显示该状态，节点投影仍按自身默认展开。Popover/Dialog、悬浮预览、滚动位置、拖拽过程、加载/错误反馈以及未加入已选列表的临时标签草稿属于会话状态，不进入工作流或 Dashboard 预设。

Gallery 的搜索、过滤列表和本地标签编辑均以 Booru 原始标签身份为准。接入 Autocomplete-Plus 时必须声明 `raw-tag` 模式：候选补全保留下划线和未转义括号，不应用面向生成提示词的空格替换、括号转义、画师前缀或自动逗号；人物标签等带括号的站点标签必须能直接用于搜索与精确匹配。

- 两个浮层共享同一工具面板结构：带语义图标、标题、说明和上下文标签的紧凑 Header，中部使用有边界但低对比的功能分区，底部集中显示应用方式或主操作。不得继续使用松散的单列字段堆叠。
- 筛选浮层在同一行并列展示 Rating 与排序。Rating 选项使用两列可扫描选择块，并实时显示已选数量；排序保留完整的共享美化下拉框。应用按钮固定在 Footer 右侧，并明确说明刷新不会影响当前选择。
- 提示词浮层优先利用横向空间：类别使用三列选择矩阵；格式转换与排除标签在下方并列。每个转换项同时显示名称和结果说明，排除标签提供可理解的示例占位。Footer 明确提示修改自动应用，不伪造保存按钮。
- 浮层宽度分别以约 420px 和 480px 为基准，同时受视口宽度约束；窄视口下自动改为单列。所有文字、控件和焦点状态必须在暗色与亮色主题中可读，动效遵循共享 reduced-motion 规则。

## 浏览与选择

- 浏览页使用自然宽高比虚拟瀑布流。卡片按最短列放置，同高时优先左列。
- 来源频道只展示适配器明确支持的内容：Danbooru 提供今日榜、周榜与月榜，AI TAG 提供月榜；Gelbooru、Safebooru 不从局部搜索结果伪造排行榜。顶栏使用紧凑“第 N 页”控件，点击后才展开上一页、下一页和页码输入，不另起第二条分页栏。瀑布流跨过分页边界时同步当前逻辑页；刷新保留该页，来源、查询、筛选或频道变化回到第 1 页，直接跳页不加载前面的结果。
- 随机模式替代顺序分页但不改变当前来源、搜索、排行榜、收藏夹、分级或本机黑名单语义；开启时隐藏页码控件，每次抽取都以 `cache: "no-store"` 绕过浏览器 HTTP 缓存和服务端结果缓存。Danbooru 普通搜索使用官方 `random:<limit>` 抽样元标签，禁止使用会在大结果集上执行全量排序并超时的 `order:random`；Gelbooru 与 Safebooru 使用站点原生随机排序，AI TAG 按远端总量直接采样随机页，其余频道在真实返回页内安全洗牌；前端再用 Web Crypto 驱动的 Fisher–Yates 洗牌打散卡片位置。同一节点在相同来源、查询、频道、周期和分级范围内维护会话级已见集合，连续抽取和滚动补取都不得再次展示相同 `source + postId`；离开随机模式或改变该范围才清空。已见集合、随机页和洗牌结果不持久化，不进入执行 payload；唯一结果连续缺失时只做有限补取，禁止无限请求。黑名单仍由适配器在轻量列表响应上本地过滤，过滤掉的帖子不会进入已见集合。
- 页码浮层的输入值右对齐并紧邻单位，光标必须落在数字尾部而不是漂在输入区中央；页码正文不小于 12px，前后翻页按钮与跳转按钮不小于 30px，确保远距离辨识和稳定点击。
- 卡片默认只保留图片和右上角 Rating 标签，卡片不显示选择顺序数字；圆角保持克制，不超过 8px。帖子来源、ID 与分辨率默认隐藏，悬停或键盘聚焦后才随底部渐变淡入；Rating 按来源使用原生语义值，Gelbooru 与 Danbooru 显示 General / Sensitive / Questionable / Explicit，Safebooru 显示 Safe，并各自使用稳定语义色标签。
- Gallery 当前只支持可进入工作流的 JPG、JPEG、PNG、WebP 与 GIF；MP4、WebM 等视频必须由来源适配器在帖子进入瀑布流前过滤，禁止展示无法选择的卡片。
- 点击图片主体直接在“选择图片 / 取消选择”之间切换，不再打开详情，悬浮操作组不得重复提供选择按钮。编辑本地标签、能力允许的收藏、复制提示词、反推提示词和查看详情位于右上角悬浮操作组；复制提示词始终可见并按当前提示词规则复制到剪贴板，反推只在检测到提示词助手（`/prompt-assistant/api` 可达）时出现，调用其视觉分析接口；反推期间卡片抬起并投射节点强调色光晕，表面叠加一道带亮边的纵向扫描光带，直到返回后以带缩略图的 Dialog 呈现结果并支持一键复制关闭。每项使用独立语义色，并通过错峰淡入、位移和悬停提升建立动作层级。指针点击造成的焦点不得让操作组在离开卡片后滞留；键盘 `focus-visible` 仍能展开操作。悬停时 Rating 标签暂时淡出，为操作组让位，收藏失败回滚原状态。
- 帖子被选中后，图片只覆盖低不透明度的轻量压暗层，不能让原图失去色彩和主体辨识。中央使用不超过 34px 的勾选标记，输出顺序作为独立的小型角标贴在标记右下方，避免把勾选和数字挤进一个过大的实心圆；蒙层不得使用高成本的逐卡片模糊，未选中时不占用卡片角落。
- 操作组按卡片自然比例自适应：横图横排、竖图竖排、接近方形时两列混排。卡片最小宽度下的横排尺寸必须完整容纳当前来源的全部操作按钮；响应式只使用帖子比例数据，不为卡片增加容器查询或 ResizeObserver。
- 站点声明收藏读取或写入能力时，卡片和详情始终显示收藏按钮，不能因为本机尚未配置凭据而隐藏入口。支持写入但缺少凭据时，点击按钮显示账户说明并提供打开 Gallery 设置的主操作，不发送注定失败的网络请求；仅支持读取时明确说明当前为只读。完全不支持账户收藏的来源不显示按钮，不能伪装成登录后可用。
- 浏览与搜索默认匿名可用，只有来源明确声明的凭证动作才要求凭据（如 Gelbooru 官方自 2025-06 起对所有 dapi 请求强制 api_key + user_id）；前端按“来源 authRequired 或当前频道需要凭证”统一判定，未配置时显示持久错误横幅并引导打开设置，不发起注定失败的匿名请求。
- 滚动只挂载视口及上下 0.75 个视口内的卡片；图片离开范围时，已完成解码的元素转移到受限会话池，其余图片立即释放 `src`。快速滚动期间新挂载卡片只显示静态占位，滚动停止后才统一补挂图片源，避免滚动帧内持续产生图片请求与解码；同期的 sample 预取和逐卡片 shimmer 动画同样暂停到滚动停止。
- 媒体统一经本地代理下载（会话与连接池按事件循环隔离复用，避免每张图重新握手；执行循环与服务器循环各自持有连接池），并按 URL 落盘缓存到用户目录；缓存与执行原图共用 `cacheBudgetMiB` 预算按最近使用顺序修剪，设置页清理缓存时一并清除。缓存命中由路由按文件流式发送（只读头部行、逐块传输、正确 Content-Length），不把整图读入 Python 内存；响应标记 `immutable`，命中浏览器缓存时零重验证。重复浏览、刷新或重新打开画廊时命中缓存即时出图；上游 5xx / 断连等瞬时失败自动退避重试，客户端断开不会取消共享下载（结果仍落盘供后续命中），上游间歇限流（404 / abuse 响应）由服务层退避重试。
- 卡片 DOM 结构与会话内已解码图片双层回收：瀑布流卸载的卡片整棵子树进入受限卡片池（上限 48 张），重挂时只按新 post 重绑定（图片、选中态、Rating、操作可见性），不在滚动帧内重建元素与监听；换绑时旧图若已解码则连同位图进入 detached 会话池，新图优先从池中取回。图片事件通过当前持有视图委托，迁移无需拆装监听；缓存键使用稳定的 `src` attribute，禁止用绝对 `currentSrc` 与相对代理 URL 混用。会话池同时受张数与解码像素预算约束，淘汰只释放 detached 图片，绝不能清空仍挂载图片的 `src`。滚动回看直接出图，不再重新请求或解码；池外或首次加载的图片显示轻量 shimmer 占位（transform 动画，`prefers-reduced-motion` 下关闭），加载完成淡入，禁止出现无占位也无内容的空白卡片。
- 卡片图片加载失败时不显示浏览器破图：卡片进入错误态，显示语义图标与“加载失败”文字的可点击占位（点击重新加载）。已知失败的预览 URL 进入会话级短时记忆（约 15 秒，限量 LRU）：期间重挂该卡片不再重复请求注定失败的地址，直接走 AI TAG 恢复链路或保持可重试错误态；瞬时失败过期后自动获得再次加载的机会。
- 卡片显示有序选择编号。详情只在悬停、打开或选择时按需请求，搜索页不逐帖补全标签。
- 指针稳定悬浮后显示节点外的大图预览卡，并逐项复用 `Aaalice_NAI_Launcher` 的 Gallery 悬浮层结构：固定 320px 卡宽、12px 圆角与强调色双像素边缘，优先出现在卡片右侧，空间不足时翻到左侧。图片区在浮层首次创建时优先使用触发卡片中已解码缩略图的真实宽高比，接口 Summary 尺寸只作为回退；宽图随比例缩短、最低 150px；普通竖图使用 `contain` 完整显示，按卡宽计算出的自然高度超过视口可用图片区时则进入超长图模式：图片保持卡片宽度与原始比例、从顶部开始只展示视口可容纳的片段，不把整幅漫画缩成难以辨认的窄条。Detail 与 Sample / Large Preview 迟到后只更新内容和信息区，不再改写图片区高度或播放高度过渡，避免底栏出现后整张浮层重新居中造成图像上下跳动。图片区与下方信息区使用独立 Grid 行；信息区按实际内容动态增高，最低 40px，最高不超过 240px 且不超过当前视口高度的 35%，达到上限后才在内部滚动。信息区增高时图片区自动使用视口剩余高度，超长图继续从顶部展示片段；禁止覆盖图片区或用 `cover` 裁切制造“底栏覆盖图片”的效果。下方信息区依次显示分辨率、评分、收藏数与 Rating，以及 Artist 最多 3 个、Character 最多 4 个、Copyright 最多 2 个标签。三类标签分别使用画笔、人物、影视图标与类别色，保留下划线转空格后的原文；中文界面通过 Autocomplete-Plus 翻译管线异步追加 `原文 (译文)`，浮层关闭后不得写回迟到结果。整卡受当前视口高度约束，视口边缘仍由共享 Tooltip 强制收进屏幕。先用已缓存缩略图立即占位（Sample 已预取就绪时直接以 Sample 起步），再按需获取 Detail，并只升级为站点 Sample / Large Preview，禁止为一次悬浮下载原图。升级继续使用双层交叉淡入；较大预览仍在请求或解码时，图片右上角只显示小型半透明旋转图标。指针离开、卡片卸载或当前 Tooltip 已切换时，迟到的 Detail 与翻译都不得更新旧预览。
- Gallery 节点对当前视口及 overscan 范围内最多 12 个帖子预取 Sample / Large Preview，不预取 Original；Sample 地址随搜索结果返回，大图预取不依赖 Detail 请求，Detail 只在悬停、打开或选择时按需请求（其标签分类按帖缓存，不批量触发上游限流）。预取队列最多同时执行 4 项，同一帖子在同一代页面中只挂一个任务，图片被淘汰后重新进入可视区时允许再次预取；AI TAG 的预览即原图，不进入批量预取。前端会话池最多保留 128 个 Detail 请求和 16 张已加载大图；重复悬浮直接使用已就绪图片，不再显示转圈。搜索重置、来源/频道/页码切换时立即清空待执行任务、轮换大图池并取消尚未完成的旧页图片加载，节点销毁时释放全部引用；失败项从缓存移除以允许重试。
- 工作流恢复时，搜索请求必须在同步清空瀑布流之前进入 loading 状态，防止空列表的 near-end 回调并发启动另一页请求。分页结果同步 append 时若 near-end 回调被 loading guard 拒绝，必须在游标与 ended 状态落定、loading 清除后重新检查 near-end，不得依赖用户先向上滚过重置阈值。虚拟瀑布流在同步接收结果后先即时绘制，再于下一动画帧按已恢复的 DOM widget 几何重绘一次；刷新网页后不得依赖用户手动刷新才能挂载完整可视区域。
- 浏览区的状态横幅按场景分位：加载中与“已到底”保持底部居中；错误横幅在瀑布流没有任何图像卡片时（首次加载、凭证缺失等）定位到浏览区顶部，已有结果时回到底部，避免把空页面的错误误认为普通状态条。凭证缺失与 TLS 证书校验失败属于持续状态：横幅保持显示直到配置完成或下一次刷新，不自动消失；点击凭证错误直接打开 Gallery 设置，点击 TLS 错误打开完整诊断。保存设置时若任一来源的凭证状态发生变化，自动对全部画廊节点重新发起首页搜索。
- 已选卡片使用明显的蓝色提亮覆盖层，中央标记只表达“已选确认”，卡片不展示输出顺序数字。所有标记共用同一个全局尺寸变量，任何印章、图案或后续新增样式都必须通过该变量统一缩放，禁止为单款覆盖最终显示尺寸。标记样式是所有 Gallery 节点共享的全局设置，提供 43 种可视化预览：日期检验章、圆形双圈、横条、椭圆、方章、竖章、八角章、齿边章、邮戳波纹章、检疫合格章、全国包邮章与全国可飞章等；参考图中可辨认的文字应作为独立款式保留，不用通用文案替代。切换后现有节点立即更新，不写入工作流。
- 专属 SVG 图案通过单一注册表按样式工厂创建；每个标记实例的图案槽在切换时只挂载当前样式的一个 SVG，普通样式保持空槽。禁止把所有专属图案常驻 DOM 后依赖互斥隐藏属性，以免 SVG 隐藏语义或宿主样式失效后发生图层叠加。新增专属图案只扩展注册表与对应样式，不修改现有样式的互斥逻辑。
- 方章、竖章、圆形中式章和横章使用共享 SVG 模板，把外框和文字基线放在同一 viewBox 坐标系内；不得用 HTML 三段文字、CSS 多层 mask、虚线或噪点模拟磨损，也不得依赖字体盒尺寸的换行模拟印章排版。模板按形状和文字行定义扩展，设置页预览必须以接近卡片实际显示的尺寸呈现，复杂文字不能依靠缩小来塞进选项。
- 选中页使用定高虚拟列表。顶部同时说明输出对数；每行依次显示拖动抓点、顺序号、缩略图、来源与格式、图片元数据与最终 Prompt 摘要。顺序就是 `images` 与 `prompts` 的输出顺序；仅拖动抓点可重排。
- 点击文字区直接打开帖子详情，并复用详情中的标签编辑、搜索与黑名单操作；删除按钮仅在行悬停或键盘聚焦时淡入，不常驻占用布局。
- 拖动重排时显示节点强调色插入位置线：根据指针在目标行上半/下半区判断插入到该行之前或之后，两端带圆点的固定定位横线标出落点；被拖动行走半透明虚线边框。原位无效落点不显示指示线。拖出列表、结束拖动、切换视图或完成放置后清理指示状态。
- 已选行只在悬停缩略图时复用浏览页大图预览卡（受“显示悬停详情”设置控制，先缩略图占位再按需拉取 Sample）。右侧文字区不再创建独立 Prompt 浮层，点击或键盘激活时直接打开帖子详情，所有标签编辑、加入搜索和黑名单操作均复用详情实现。滚动列表、拖动重排、切换视图或行卸载时关闭图片预览。
- 空选择使用居中的轻量引导，不保留虚假的列表卡片或大面积装饰。
- 搜索错误保留选择；分页错误保留已有瀑布流；收藏失败回滚本次按钮状态。
- 全局内容黑名单按网站原始标签精确匹配，并在帖子进入卡片集合前生效；搜索、排行榜和收藏夹使用同一规则。所有来源都只使用轻量列表响应自带的标签在本机过滤，不向远端查询拼接排除标签，因此不占用站点搜索标签槽位、不泄露黑名单，也不改变来源原有的登录要求；禁止为黑名单逐帖加载 Detail。适配器每页只规范化一次黑名单集合，再以集合相交过滤帖子。若过滤后内容不足以填满视口，画廊根据瀑布流已缓存的总高度连续补取最多 4 个后续页面；仍不足时显示“继续查找”操作，禁止无上限后台请求。从详情快捷加入黑名单时，所有 Gallery 节点立即刷新，并移除既有选择中包含该标签的帖子；节点不显示“已屏蔽”占位。黑名单不改变其余帖子的最终 Prompt。
- 加载、到底和错误状态必须同时显示语义图标与文字；`hidden` 或空状态不得留下无文案胶囊。普通瞬时错误 6 秒后自动消退；横幅允许完整换行并可点击打开错误详情，详情以可选择、可复制的原文保留完整主机、证书原因和底层异常，同时提供重试。TLS 证书错误使用短小本地化摘要与系统时间、HTTPS 代理/抓包证书、系统根证书排查说明，禁止通过关闭 SSL 校验伪造恢复。瀑布流只允许纵向滚动，不显示横向滚动条。瀑布流与已选列表的滚轮遵循当前前端的焦点式滚轮捕获协议：画廊业务根声明 `data-capture-wheel="true"`，两个滚动容器声明 `tabindex="0"` 并在 `pointerenter` 预先 `focus({ preventScroll: true })`；焦点已在画廊内或外部文本编辑控件时不抢夺。卡片主体或悬浮操作被指针点击后，若临时焦点仍在该卡片控件上，必须直接交还瀑布流而不是 `blur()` 到 `document.body`；键盘激活继续保留控件焦点，Dialog 已取得焦点时不得抢回。业务层禁止 `preventDefault()`、`stopPropagation()`、捕获阶段监听或伪造 WheelEvent；Standard 模式的 `Ctrl` / `Meta` + 滚轮留给宿主缩放。

## 微动效与精致度

动效只服务于状态确认、空间来源和可操作性，不持续占用主线程：搜索框从右侧原位展开；浏览/已选切换以同一 thumb 的弹性滑动和内容轻微淡入建立方向；选择或取消时卡片边缘只播放一次绿/红确认环，数量文本同步轻弹；收藏成功只让收藏按钮短促回弹。图片卡片悬浮时由内部 Surface 抬升并增强阴影，根据指针在卡片内的位置产生不超过约 4° 的双轴倾斜，同时让径向高光与斜向光带跟随指针扫过；瀑布流负责定位的卡片根元素不得参与倾斜。悬浮按钮错峰展开，已选行、详情事实块和设置卡片只做 1–2px 抬升与轻微表面变化。标签数量仅在实际变化时轻弹，恢复原始标签必须同步刷新数量。

所有动效使用主题 token、`transform` 与 `opacity` 为主，单次约 140–340ms，不给每张卡片增加观察器或常驻动画；指针移动由瀑布流容器统一委托监听，只在单个 `requestAnimationFrame` 中合并更新 CSS 变量并读取指针下方一张卡片的几何，卡片离开虚拟范围时必须取消待处理帧和监听器。节点宽度改变导致列数或最短列归属变化时，已挂载卡片必须通过位置 `transform` 平滑迁移到新列，不得瞬移；滚动和初次挂载不会触发卡片入场动画。`prefers-reduced-motion: reduce` 下关闭 Gallery、详情、编辑和设置中的动画及过渡，并停止指针倾斜计算。

## 详情与本地编辑

详情 Dialog 使用“原图舞台 + 信息检查器”双栏结构：左侧先立即显示已预取的 Sample / Preview，再在独立加载成功后无闪烁升级为 Original；原图失败时保留预览图、显示明确错误并允许重试，关闭 Dialog 或销毁节点时取消仍在进行的原图加载。卡片悬浮操作与详情页脚均提供“下载原图”；详情中的“打开原图”使用外部打开图标并继续在新标签页查看，下载操作使用独立下载图标和加载反馈。图片舞台支持以指针位置为中心的滚轮缩放、放大后拖拽平移、键盘缩放与移动，并提供显式复位和双击复位；右侧集中展示来源、帖子身份、尺寸、格式、Rating 和五类标签。窄窗口自动变为上下结构。检查器采用层叠工具盘语言：身份、事实数据和标签类别分别落在无边框的错层表面上，通过圆角、间距与定向柔影建立层级，禁止用连续横线或竖线切割。事实数据使用紧凑微型仪表块；标签类别使用中性浮层，类别色只出现在识别点、标签和极轻阴影中，避免彩色边框与彩色背景叠加成大色块。胶囊不常驻操作图标，单击在胶囊下方弹出操作菜单、右键在指针位置弹出，菜单提供“编辑”“复制标签”“加入搜索框”和“屏蔽标签”：编辑在原位展开输入框并保存为当前帖子本地修改，复制写入剪贴板并在胶囊上给出短暂光晕反馈，屏蔽则加入唯一全局黑名单、关闭详情并从所有 Gallery 节点隐藏含该标签的帖子。左键不直接触发屏蔽。中文界面下详情胶囊接入 Autocomplete-Plus 的三层汉化管线（ffdkj 词典 → AI 缓存 → DeepSeek），译文到达后以类别色第二行就地附加到对应胶囊，不重排已有标签；扩展未安装或接口不可用时静默保持英文。Footer 提供原站、代理原图、复制图像（转为 PNG 写入剪贴板）、选择及 capability 允许的收藏操作。

本地标签编辑以真实缩略图和本地修改说明开场，Artist、Copyright、Character、General、Meta 五类分别使用带实时数量的胶囊编辑区。胶囊与帖子详情共享类别色和单击编辑、右键操作语义；末尾只常驻一个加号胶囊，点击后原位展开输入框，支持英文逗号、中文逗号、顿号与回车批量添加，完成、取消或空内容失焦后收回。允许增删、恢复和复制 Prompt。只有已选快照进入工作流；不修改远端帖子。

筛选 Popover 先说明当前来源，再显示该来源实际支持的 Rating 与排序；无 Rating 能力时显示明确说明而不是空控件。Prompt Popover 明确说明输出按已选顺序生成，并把类别、转换选项和精确排除标签分成三个阅读区。

## 设置

ComfyUI Settings 中只有一个 `Booru Gallery` 入口。设置 Dialog 使用同一个四段导航切换“账户 / 浏览 / 提示词 / 存储”，避免把所有表单一次堆进长页面。Dialog 标题和当前导航已经明确页面身份时，不再为各页固定增加副标题；只有影响风险理解或功能边界的说明才放在对应操作附近：

- 每个来源卡片显示稳定来源身份、已配置 / 未配置 / 公开访问状态、实际能力、凭据、默认 Rating、连接测试及局部状态；凭据清除使用紧凑图标动作，连接测试使用旋转、成功和失败三种反馈。需要凭据的来源，其凭证输入下方必须有直达站点官方账户页的链接（`credentialsUrl`），新窗口打开且不泄露来源或路径到配置；无凭据来源不显示该链接。
- 浏览页只包含默认来源、内容黑名单和 Tooltip；黑名单使用独立的内容保护卡，显示实时标签数量、作用范围和“隐藏帖子而非修改 Prompt”的边界。Prompt 页只影响新节点；存储页集中管理超时、缓存预算和带说明的缓存清理危险操作，预算同时约束搜索/详情内存缓存、原图下载缓存与媒体磁盘缓存，清理操作清除全部三类缓存。
- 四个页面共享稳定内容区域，切换时只做短促淡入位移；表单、测试状态和已输入凭据 DOM 不因切页重建。
- API Key、用户 ID、用户名和缓存不进入工作流；节点更多菜单只打开同一设置 Dialog。
- “排除标签”只有一份全局真源：当前 ComfyUI 用户目录中的 Gallery 内容黑名单。详情页快捷屏蔽、提示词处理浮层的排除标签输入框和 Gallery 设置页必须读写同一列表；列表中的标签既会隐藏包含它的帖子，也会从已有选择的输出 Prompt 中排除。所有画廊节点、来源和工作流共用该列表，切换、新建或加载其他工作流不会清空；旧版 `promptDefaults.excludedTags` 在读取时合并进黑名单并清空，不保留第二套状态。
- “输出过滤标签”是黑名单的并行全局列表（`outputFilterTags`，同一设置文件）：只从输出与复制的 Prompt 中精确剔除标签，不隐藏帖子、不移除已有选择，适合 watermark、画师名等不想看进 Prompt 但仍想浏览的标签。提示词处理浮层提供独立“输出过滤”页签，详情标签菜单提供“输出时过滤标签”快捷入口，Gallery 设置“提示词”页提供同一列表的编辑；三处读写同一份真源。保存只刷新已选视图与 Prompt 预览，不触发搜索重置；执行 payload 与 Python 端 `PromptOptions.output_filter_tags` 走与黑名单相同的精确匹配管线。

## 尺寸与双模式

默认尺寸约 760×760，稳定内容下限为 620×300。双行工具栏增加的高度由默认高度补偿，默认内容视口不因此缩短；620px 最小宽度仍能容纳完整工具栏和四列最小卡片，不额外放大节点。`computeSize()` 与 `onResize()` 共同约束宽高，避免工具栏和条目操作区被压缩到失效；高度下限与当前节点高度无关，禁止把已经拉高的几何重新写成最小高度。节点缩短时只让瀑布流或已选列表内部滚动，ResizeObserver 只观察瀑布流容器。

DOM widget wrapper 与 Gallery 根不接收指针；只给顶栏控件、瀑布流滚动区和已选列表开启命中。内容在底部保留 13px 安全带，并在左右各留 10px，使左下角和右下角都直接落到 LiteGraph 原生 resize 命中区。进入原生 resize 手势后，Gallery 根及全部后代立即关闭命中。Classic 与 Nodes 2.0 共用内容结构，标题、socket、节点拖拽和缩放继续由 ComfyUI 管理。
