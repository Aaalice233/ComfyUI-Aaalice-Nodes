# QuickGroupManager 设计规范

QuickGroupManager 是当前图的纯前端组控制器。它不参与 Prompt I/O，只负责发现可视组、显示实际状态，并把用户操作作为原子图变更提交。

## 节点职责

- 每个组只提供一个启用开关；节点级 Mute / Bypass Switcher 统一决定关闭模式。
- 颜色范围只决定当前 Manager 显示和手动管理的组；联动目标可以跨颜色。
- 多个 Manager 的过滤、排序和规则相互独立；最后一次用户操作决定重叠范围的实际状态。
- 外部组菜单、撤销重做和其它 Manager 只触发显示同步，不执行本节点规则。
- Subgraph 节点可以像普通组成员一样切换，但不递归修改其内部图。

## 顶栏与尺寸

- 标题、Mute / Bypass Switcher、颜色按钮和刷新按钮保持同一行，不显示“关闭方式”或“颜色过滤”等冗余标签；Switcher 与颜色、刷新工具组成靠右操作组。Switcher 使用图标与文字双重表达两种关闭模式，并为中英文标签保留稳定宽度。
- 最小宽度保证标题和右侧 Switcher / 工具组完整显示；Classic 在节点尺寸回调中约束，Nodes 2.0 同时把真实下限写入宿主节点的 inline `min-width`，使原生四角缩放手柄读取同一数值。用户可以自由拉宽，但不能继续缩窄到顶栏溢出。
- 节点允许自由增高，但不能缩到当前条目所需的内容下限；工具栏、列表与空状态始终从顶部紧凑排列，额外高度只留在内容之后，不拉伸条目或行间距。
- Classic 中主体 DOM widget 的 `minHeight` 与 `maxHeight` 同时锁定为当前内容高度。Nodes 2.0 不读取这两个数值来生成 Vue 网格轨道，因此必须把 QuickGroupManager 的 widget stack 收口为 `30px + min-content` 的顶部内容轨道；节点主体可以继续增高，额外空间留在 widget stack 与底部包标识之间。
- 节点背景、外轮廓和圆角由 ComfyUI 原生层负责；标题栏与内容 DOM 都保持透明，不添加颜色不一致的第二层表面或外框。
- Switcher 的滑块与选项图标保持稳定 DOM identity，通过 class 与 transform 完成平移动画，并区分 Mute / Bypass 状态色；语言刷新只更新标签文本，不能重建或覆盖图标。

## 组列表

- 每行固定包含拖拽手柄、可截断名称、画布定位、联动状态和单一启用开关；颜色只属于筛选范围，不在条目中重复显示。节点数量和启用/禁用文案不作为重复信息展示。
- 画布定位使用轻量取景框图标，把完整组边界平滑适配到当前视口；定位只改变视图，不选择节点、不修改组或工作流状态。
- 条目使用轻量块面和间距形成独立层级，不用贯穿列表的横线模拟表格行。
- 行高和行间距保持固定紧凑，列表上下只保留必要收口空间；节点最小高度只由可见行数、行间距和列表边距决定，手动增高时列表不参与剩余高度分配。
- `enabled` 使用稍亮的强调色表面，`disabled` 使用较暗的中性表面，`mixed` 使用 indeterminate 和警告色；空组禁用并给出可访问提示。状态不依赖文字，开关和条目整体都保持可操作。
- 拖拽只能从手柄开始，并显示插入位置；`Alt+↑/↓` 提供键盘排序。
- 过滤状态下只改变可见组的相对顺序，隐藏组顺序保持不变。

## 颜色与刷新

- 颜色浮层支持全部、多颜色和无颜色组；顶栏按钮始终保持中性图标外观，悬浮 tooltip 使用色块和颜色代码列出当前过滤范围，aria-label 提供等价文本。
- 普通组开关、联动标记和拖拽插入提示使用 Manager 当前节点强调色；关闭态保持中性并降低亮度，mixed、Mute / Bypass 和实际筛选颜色继续使用各自语义色。Mute / Bypass 使用带图标、颜色和滑块动画的切换器。
- 当前画布颜色实时读取并规范化；已经失效的已选颜色保留并显示警告。
- 切换过滤只改变列表和管理范围，不改变组模式。
- 刷新只重新扫描组、颜色、成员和实际模式，不触发联动或修改节点模式。

## 侧边栏导航

- 整体 QuickGroupManager 控件的标题直接读取对应节点的实时 `getTitle()`，因此节点重命名、复制和加载后的标题与画布保持一致；用户在侧边栏设置的 `labelOverride` 仍优先保留。
- Aaalice Workspace 的“组导航”是独立于 Manager 过滤范围的人工导航清单，用来替代持续占据画布的悬浮入口；任何组都不会自动加入。
- 用户从当前图显式勾选要加入的组；导航项保留手动添加顺序，显示真实组颜色、节点数量和启用状态，点击主体适配完整组边界。组失效后保留导航项和名称快照，以便用户明确移除。
- 新的导航项不再提供单组直达键设置；旧工作流中的历史 `1`–`6` / 小键盘值仍兼容读取，但用户只需配置统一的轮盘激活键。
- 每个导航项可以独立设置水平和垂直目标偏移，以及 10%–300% 的目标缩放倍率。偏移使用整数画布坐标，默认 `(0, 0)`；缩放默认 82%，表示组边界目标占据视口的比例，超过 100% 允许主动裁切大组。导航时先取实时组边界，再应用偏移和缩放。条目次要信息明确显示非零偏移和当前缩放。
- 导航清单、条目顺序、偏移和缩放以版本化模型写入工作流 `extra`，增加、移除、排序和修改设置都进入图事务并提醒保存；搜索和定位只属于会话状态。实时组状态通过 `graphChanged` 合并刷新，不递归进入 Subgraph。
- 组跳转轮盘严格复用这份人工清单，不读取或复制 QuickGroupManager 的组状态。默认按住 `Backquote`（Tab 上方的反引号键）打开，移动指针按角度高亮方向，松开立即沿同一实时组定位路径跳转；侧栏轮盘按钮也必须按住并拖动，松开后触发，单击不会直接跳转。
- 轮盘每页最多显示 8 项，按清单顺序分页；缺失组保留为禁用扇区并标记 `Missing`，不参与跳转。打开后可用方向键循环、鼠标滚轮或 `PageUp` / `PageDown` 翻页；松开激活键/指针手势提交，`Escape` 取消，指针停在中心安全区并释放时取消。
- 轮盘激活键与导航清单一起写入版本 3 的工作流 `extra`，只保存一个按键；`Backspace` / `Delete` 用于清除设置。轮盘的打开、选择、取消和跳转不产生工作流历史记录。

## 侧边栏整体控件

- QuickGroupManager 以一个稳定 `quick-group-manager` Binding 添加到 Dashboard 侧边栏，不把组拆成独立控件，也不创建第二份 Manager 状态。
- 侧边栏控件在同一行显示节点标题与 Mute / Bypass 操作；模式切换器和刷新按钮作为同一工具组靠右排列，标题占用剩余空间并在必要时截断，不能相互覆盖。标题和工具保持统一的 32px 头部高度；下方只保留按内容展开的组列表，不重复显示工作流组数量、节点数量或启用/禁用文案，实时状态通过条目明暗和共享 Toggle 表达。组开关和模式转换都委托 `quick_group_manager_runtime.js`，失败时整次图事务不落部分结果。
- 侧边栏卡片运行时按标题栏、列表收口和当前可见组行数计算 `layoutProjection.rowSpan`；Dashboard 的通用矩形投影在页面和布局组内同步重排后续占位。可见条目减少时立即回收空白，不保留固定 52 行下限，也不改写 `data-drop-*` 或工作流中的规范布局。组列表按内容自然展开，不建立独立滚动区；超出侧栏视口时由当前页面的 Scroll Surface 承载，页面滚动只滚动当前页面，不触发其它页面切换。
- 每个非空组都有独立的共享 Toggle，可直接切换该组；组条目的整行也可点击或通过键盘 Enter / Space 切换。空组保留状态但禁用开关并提供原因。单个组操作失败只通过宿主错误通道反馈，不阻断其它组的渲染。
- Dashboard 预设只捕获当前组开关对应的成员启用/关闭状态；恢复时按稳定组 ID 和节点 ID 应用，关闭成员统一使用 Manager 当前的 Mute / Bypass 模式，缺失成员只跳过不可恢复项并保留其它有效状态。颜色范围、排序、关闭模式与联动规则属于 Manager 节点的共享配置，不按预设保存或恢复；旧预设中的 Manager 配置与历史关闭模式在读取时迁移移除。
- 节点、侧边栏和预设只在 Manager 所属 graph 内工作，不能因侧边栏显示而扫描或改写其它 graph。

## 联动规则

- 每个源组可分别配置“开启时”和“关闭时”的目标动作；同一阶段中一个目标只能有一个最终动作。
- 仅当源组已有联动时，联动按钮悬浮或聚焦才显示预览；预览按触发阶段列出目标组颜色、名称和最终动作。
- 编辑器使用锚定浮层，支持搜索、键盘、Escape、点击外部关闭和焦点返回。
- 保存前拒绝自引用、环路、缺失目标和冲突路径；已删除目标保持可见，允许修复或删除。
- 执行前先计算完整级联和节点模式变更；跨颜色目标作为终点，规则不跨 Manager 继续传播。
- 同一节点因重叠组收到不同最终模式时整次操作中止；失败不得留下部分修改。

## 验收重点

- 顶栏在最小宽度下不换行、不截断标题，Switcher 与工具组整体靠右；节点可自由拉宽和增高，缩短时受当前内容下限约束，增高后内容仍靠上且行距不变。
- 明暗主题下文字、边框、状态和焦点均清晰；交互目标不小于 32px。
- 修改和清除 Manager 节点颜色后，普通控件强调色即时同步，不改变筛选颜色或 Mute / Bypass 的业务含义。
- 过滤、拖拽、键盘排序、保存重载、复制、撤销和重做保持一致。
- Mute / Bypass 批量转换只影响当前颜色范围内已经关闭的组，且不触发联动。
- 单层、多层、跨颜色和冲突联动均按预计算结果原子提交。
