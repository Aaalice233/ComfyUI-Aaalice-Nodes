# Operation Panel 设计规范

Operation Panel 是工作流作者搭建的 WebUI 风格操作界面，用于集中调值和查看结果；它不替代节点图，也不提供独立执行流程。

## 工作区外壳

- 侧栏入口只作为原生展开/收起开关；激活后折叠其内容面板和分隔条，只保留侧栏图标，不得同时呈现侧栏版与工作区版界面。
- Operation Panel 使用唯一工作区实例，从侧栏图标边缘铺满原节点区域；再次点击同一入口时销毁该实例并完整恢复节点图。
- 工作区背景位于 ComfyUI 原生工具栏下方，页面与编辑命令位于原生工具栏的空白区域上方；不得提升、复制或遮挡原生工具栏容器。
- 浏览模式只显示最终操作界面；编辑布局在原地解锁画布，不增加常驻属性栏。
- 面板不复制队列、运行或任务管理控件。

## 统一命令栏

- 页面标签、预设和布局编辑使用同一条命令栏，并与 ComfyUI 原生图形、扩展管理、预览、运行和任务控件共用顶部视觉基线。
- 命令栏只占用原生面包屑与右侧原生操作区之间的可用空间，不用整宽背景切割工作区。
- 单个无名页面不显示页面标题或导航；多页面使用文字标签与下划线。
- 空间不足时先隐藏次要按钮文字并保留图标、tooltip 和可访问名称；不得覆盖原生控件。
- 顶部使用连续工作区底色和一条内容分界线，不使用透明洞、重复标题块或额外卡片外壳。

## 页面

- 单个无名页面隐藏导航；新增第二页时要求命名当前页和新页。
- 多页面使用文字标签与下划线，不使用胶囊 tabs。
- 页面用于“文生图”“图生图”“高清修复”等独立操作界面，不作为轮播卡片的替代品。
- 切换页面是临时浏览状态，不标记工作流修改；作者可以设置默认页面。
- 删除页面只移除该页 Modules，不删除工作流节点，并形成可撤销操作。

## 布局编辑

- 编辑时卡片内容只读，整卡承担选择、拖动和宽度调整。
- 支持单选、`Ctrl/Cmd` 多选和 `Shift` 连选。
- 上下文操作包括组合、组合为轮播、解组、对齐、分布、等宽、移动页面、样式、锚点和移除。
- 拖动过程只预览，松手后写入一次撤销记录。
- 从面板移除只在编辑模式提供；直接执行并可撤销，不弹重复确认。

## 锚点与空间

- `1440×900` 与 `1920×1080` 是最小设计基准而非固定画布；默认 `1440×900`。工作区更宽时画布、12 列网格及中间/右侧锚点一起展开。
- “自适应窗口”持续使用当前可见工作区，并保留 `960×640` 安全下限；该模式不保存窗口像素快照。
- 只有 Page 的 Root Module 使用九宫格锚点或横向拉伸；容器内部卡片自动排版。
- Anchor Frame 保存锚点、偏移、对齐点和宽度；高度始终由内容决定。
- 12 列主网格和 8px 小网格只用于吸附与对齐，不序列化为强制单元格。
- 拖动时推断并预览锚点；修饰键可临时关闭吸附，右键可手动指定。
- Root Modules 不得重叠；冲突模块移动到最近空位。
- 工作区窄于固定基准或缩窄后会造成锚点碰撞时，扩大运行时画布并滚动；窗口变化不得修改 Anchor Frame、产生撤销记录或标记 workflow 未保存。

## Modules

- **Node Card**：一个已主动加入的节点或 ComfyUI Subgraph；同一图对象只能出现一次。
- **Group Card**：多个 Node Cards 共用外轮廓，内部紧凑自动排列，不重复边框。
- **Carousel Group**：多个 Node Cards 或一层 Group Cards 共用位置，一次显示一个 slide。
- **Heading**：标题和简短说明，用于建立内容层级。
- **Markdown**：安全 Markdown 内容；忽略任意 HTML。

Group 只包含 Node Cards。Carousel 的 slide 只能是 Node Card 或一层 Group Card，禁止继续嵌套。

## 轮播

- 高度取所有 slides 中最高内容，切换时下方布局不跳动。
- 顶部显示圆点和左右箭头；当前或悬浮圆点才展开名称。
- 支持点击、键盘、触控板横滑和横向滚动。
- 普通纵向滚轮不得被轮播拦截。
- 作者可设置默认 slide；浏览时切换不修改工作流。

## 视觉与状态

- 卡片只提供普通、紧凑、重点和无边框四种样式，不开放任意颜色、阴影或圆角。
- 普通组合使用共享表面；内部卡片取消重复外框。
- 选中、隐藏、错误和禁用同时使用轮廓、透明度或图标表达，不能只依赖颜色。
- 普通按钮使用小圆角矩形；胶囊只保留给短标签和轮播圆点展开态。
- 标题、说明、参数和结果建立清晰字重与间距层级，避免把每一块都做成独立卡片。

## 加入、移除与预设

- 节点和 Subgraph 只能从自身右键菜单主动加入。
- 移除 Module 或 Page 只修改 Operation Panel，不删除或断开工作流节点。
- 无选择时，Value Preset 保存当前页面全部可写值；有选择时保存所选 Root Modules 及其后代中的可写值。
- Value Preset 不包含布局、节点、连线或参数定义。

## 验收重点

- 展开时只保留一个 Operation Panel 工作区实例；原生侧栏内容面板和分隔条不占位，顶栏、侧栏图标及原生工具保持可见可操作。
- 收起后恢复原生节点工作区，不遗留隐藏面板 class、portal、背景层或分隔条状态。
- 页面、锚点、多选、组合、轮播和预设在保存重载后保持一致。
- 1440、1920、自适应和窄窗口下没有重叠、截断或意外写回布局；编辑网格铺满实际运行时画布。
- 键盘焦点、上下文菜单、轮播控制和自定义 adapter DOM 可正常清理。
