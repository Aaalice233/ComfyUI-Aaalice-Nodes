# ParameterPanel 设计规范

ParameterPanel 同时服务节点图中的快速调值和独立弹窗中的参数结构编辑。节点面保持紧凑，结构操作集中在右键编辑器。

## 节点面

- 节点只显示参数值控件和真实输出，不恢复结构工具栏。
- 顶部两个角保持直角，底部沿用节点圆角；Classic 与 Nodes 2.0 外观一致。
- 参数区左侧保留安全边距，右侧为输出名称和 socket 预留独立 gutter。
- 参数行与紧凑输出栈由同一布局引擎计算，但使用各自的垂直节奏。
- 未使用输出和 Separator 对应输出在界面中隐藏，但协议槽位继续保留。
- 节点高度取参数内容与输出栈所需高度的较大值，不能截断 socket 或控件。

## 参数控件

- Slider 的名称与数值同排，轨道位于下方并占满参数内容宽度；拖动立即更新，点击数值才进入编辑。
- 少量枚举使用分段按钮，大量选项使用 select；展开、关闭、Escape 和 change 后箭头状态必须同步。
- Switch 使用真实按钮和 `aria-pressed`，轨道可以使用胶囊形。
- Seed 的锁定按钮内嵌输入框尾部：未锁定显示开锁和强调色，锁定显示闭锁和危险色；输入框边框同步状态。
- 文本、数字和下拉输入使用比节点底板更深的内嵌表面；hover 和编辑态才适度提亮。
- 临时数字编辑器使用不透明高对比表面，隐藏原生微调箭头和底层静态数值。
- 所有控件保留键盘焦点、aria 名称和足够命中区。

## 结构编辑器

- 标题栏只显示“编辑参数”和参数数量，不重复节点名称或产品说明。
- 宽屏采用参数列表 + inspector 双栏；窄屏改为上下布局。
- 左栏负责新增、选择、重排、复制和删除；次要动作默认弱化，避免按钮墙。
- 参数类型选择与新增按钮组成连续控件，统一外轮廓、焦点反馈和至少 40px 命中高度。
- inspector 直接从字段开始，不重复“基础信息”“取值规则”等卡片标题。
- Markdown 说明框在宽屏中垂直填满可用空间，长内容在框内滚动；窄屏保持稳定高度。
- Slider 的 min / max / step 三等分；Seed 的 min / max 二等分；数字使用 tabular numerals。
- Footer 固定承载草稿状态、校验错误、取消和保存。
- 删除已连接参数时列出受影响连线并确认；保存后一次性应用，形成单个撤销边界。

## Classic 与 Nodes 2.0

ParameterPanel 共用一份 DOM 控件树：

- Canvas/native 层负责静态表面、布局反馈和真实 slot。
- DOM overlay 负责输入、焦点、键盘、tooltip 和 aria。
- Classic 使用 LiteGraph 原生 slot 绘制与命中。
- Nodes 2.0 使用 Vue slot DOM 绘制与命中。

Nodes 2.0 重建 slot DOM 后，以幂等 `MutationObserver` 恢复隐藏和位置状态，不使用持续轮询。布局跨模块接口为 `computeParameterLayout(node)` 与 `syncNativeOutputLayout(node, layout)`；可见输出索引属于布局模块内部计算。

## 验收重点

- 参数名称、控件、输出名称和 socket 不重叠、不截断。
- 名称或顺序变化后，连线仍跟随稳定参数身份。
- Seed 锁定、数值编辑、枚举和动态选项在两种节点模式下行为一致。
- 保存重载、复制节点和撤销重做后状态一致。
